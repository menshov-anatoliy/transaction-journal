# Реальный риск — минусовая часть текущего результата

Реальный риск конструкции переопределяется из наихудшего результата открытых остатков на экспирации (совместный минимум платежа групп, сохранённый ADR-0021 при удалении `worstCaseUsdt`) в минусовую часть текущего результата: `max(0, −(реализованный + нереализованный + внешние корректировки PnL))`. Решено (грилл-сессия триажа #90, 24.11.2026): состав метрики показывает фактическое положение конструкции — реализованный результат, стоимость открытых опционных остатков и изменение цены открытых фьючерсов по текущим маркам, — а не дожитие остатков до экспирации; корректировки входят, потому что роботный результат — реальные деньги наравне с реализованным PnL. Формула едина для открытых и закрытых конструкций: закрытая убыточная конструкция показывает риск, равный финальному убытку. Метрика становится зависимой от котировок: при их сбое она недоступна целиком, а не считается по остатку данных; неограниченный хвост по маркам невозможен, поэтому значение `unbounded` и бейдж «∞» удаляются из контрактов и UI, статусная пара вырождается в `finite`/`unavailable`. Замороженные openspec-спеки `analytics/performance` и `ui/screens` (ADR-0023) более не источник истины по этой метрике; живой контракт фиксируют issue-спека и тесты с метками `issue:#90`.

## Considered Options

- Оставить worst-at-expiry второй метрикой рядом: отвергнуто — две «рисковые» величины с разными точками расчёта (марки против экспирация) путают потребителя.
- Знаковый исход вместо клэмпа ≥ 0: отвергнуто — дублировал бы текущий результат; ADR-0015 уже развёл уровни «риск потери» и «исход конструкции».
- Исключить корректировки из состава: отвергнуто — конструкция с роботным убытком и нулевой рыночной частью показывала бы «риска нет» при минусовом итоге.
- Обнулить риск закрытой конструкции: отвергнуто — скрытый второй режим; состав метрики един для всех состояний.
- Трёхзначный статус с неиспользуемым `unbounded`: отвергнуто — мёртвое значение противоречит чистоте контрактов.

## Consequences

- Breaking: из `realRiskStatus` уходит строка `unbounded`; бейдж «∞» удаляется из списка, превью и карточки; подпись планового риска в fallback остаётся только для `unavailable`.
- Метрика зависит от котировок: сценарий «сбой котировок не влияет на реальный риск» отменяется; при сбое риск недоступен вместе с нереализованным PnL.
- `RealRiskCalculator` с группировкой по экспирациям, узлами излома и наклонами удаляется; расчёт сводится к клэмпу в калькуляторе метрик конструкции.
