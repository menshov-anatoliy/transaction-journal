# Сборка конструкций из «Входящих» сосуществует с полным пересбором

Полный пересбор стирает ручные данные (капитал, комментарии, корректировки PnL, привязки), поэтому рабочим режимом после каждой синхронизации выбрана инкрементная сборка: она формирует новые конструкции только из нераспределённых записей «Входящих», а существующие конструкции читает лишь как контекст остатков для классификации закрывающих сделок и выбора целей усреднения — исключение составляют производные величины: имя (ADR-0005) и статус «закрыта» при исчезновении опционного прикрытия. Полный пересбор сохранён как отдельный аварийный режим для чистой базы после первичного backfill.

## Consequences

- Оба режима детерминированы порознь, но могут разойтись на одних данных: если 60-минутное окно ролла разрезано границей синхронизации (закрывающая нога привязана ранее, открывающая пришла сейчас), инкремент откроет новую конструкцию, а пересбор соединит ролл. Расхождение принято; исправление — ручная привязка.
- Инкрементная сборка запускается только вручную кнопкой: пользователь решает, когда разбирать «Входящие».
