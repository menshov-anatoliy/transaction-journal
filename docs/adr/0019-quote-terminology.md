# Котировка вместо марки

Русским термином для цены биржевой оценки инструмента (mark price Bybit) везде в проекте выбрана «котировка», а слово «марка» выведено из употребления. «Марка» читалась двусмысленно и конфликтовала с соседними терминами: «ручная пометка закрытия» (`ManualCloseMark`) не является ценой, а «маркер итога» индикатора — не термин цены. Внешние поля Bybit (`markPrice`, `markIv`) сохраняют имена внешнего API; внутренний контракт, код, БД, UI-тексты, глоссарий и specs используют `quotePrice`/`QuotePrice` и «котировку». Слова «маркер» и «маркировать» термином «марка» не являются и не меняются; Traceability ID с историческим корнем `mark` остаются стабильными идентификаторами.

## Considered Options

- «Котировка» — выбрано: привычно трейдеру, однозначно отделяет биржевую оценку от цены сделки.
- «Mark-цена», «оценочная цена» — отклонены: кальки, не живущие в русском тексте интерфейса.
- Сохранить «марку» — отклонено по требованию владельца проекта: термин не используется нигде.
