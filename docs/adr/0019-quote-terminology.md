# Котировка — каноничный термин цены биржевой оценки

Русским термином для цены биржевой оценки инструмента (mark price Bybit) везде в проекте выбрана «котировка»; прежний термин (русское слово для mark price) выведен из употребления. Старое слово читалось двусмысленно и конфликтовало с соседними терминами: «ручная пометка закрытия» (`ManualCloseMark`) не является ценой, а «маркер итога» индикатора — не термин цены. Внешние поля Bybit (`markPrice`, `markIv`) сохраняют имена внешнего API; внутренний контракт, код, БД, UI-тексты, глоссарий и specs используют `quotePrice`/`QuotePrice` и «котировку». Слова «маркер» и «маркировать» прежним термином цены не являются и не меняются; Traceability ID с историческим корнем `mark` остаются стабильными идентификаторами.

## Considered Options

- «Котировка» — выбрано: привычно трейдеру, однозначно отделяет биржевую оценку от цены сделки.
- «Mark-цена», «оценочная цена» — отклонены: кальки, не живущие в русском тексте интерфейса.
- Сохранить прежний термин (русское слово для mark price) — отклонено по требованию владельца проекта: термин не используется нигде.
