# Индикатор финрезультата: удаление маркеров изменения результата

Маркеры изменения результата (ADR-0021, модель вкладов — ADR-0022) удаляются
полностью — решение владельца (triage #89, 23.11.2026): после роллирования
цепочка меток перестала быть информативной. Ролл — единое окно сборки и одна
метка, поэтому серия последовательных роллов даёт цепочку близких значений,
которая не читается; порог проявления проблему не решает. На шкале индикатора
остаётся только круглый маркер текущего результата с подписью под полосой;
плановые границы шкалы, зоны планового риска/профита и сверхприбыль не
меняются.

Удаляются: номерные бейджи над полосой во всех видах индикатора (полный,
средний, компактный) и расшифровки меток; публикация маркеров и перечней
операций в API-контрактах и read-моделях (`resultMarkers` карточки,
`lastResultMarker` списка и превью); калькулятор вкладов операций,
журнальная материал-подготовка и DI-связывание ридера; термины глоссария
«маркер изменения результата», «порог проявления маркера», «расшифровка
маркера», «вклад операции».

## Considered Options

- Оставить только последний маркер без номера: отвергнуто — его накопленный
  итог дублирует маркер текущего результата с иной семантикой (зафиксированный
  без нереализованной части) и не решает проблему цепочки роллов.
- Повысить порог проявления, чтобы сворачивать цепочки роллов: отвергнуто — у
  подбора порога нет критерия правильности, а накопленный дрейф между метками
  всё равно читается плохо.
- Убрать только из UI, сохранив публикацию в API: отвергнуто — контракты без
  потребителя противоречат чистоте контрактов; прецедент полного удаления —
  `worstCaseUsdt` (ADR-0021).

## Consequences

- Breaking: из API и read-моделей уходят `resultMarkers` (карточка) и
  `lastResultMarker` (список, превью) вместе с перечнями операций расшифровки;
  калькулятор вкладов удаляется целиком.
- ADR-0021 и ADR-0022 полностью заменяются настоящим ADR. Замороженные
  openspec-спеки (`ui/screens`, `ui/design-system`, `analytics/performance`,
  `http-api/transport`) не переписываются — живой спецификацией становятся
  тесты с метками `issue:#89` (ADR-0023).
- Термин «маркер текущего результата» и его определение сохраняются; ссылки
  на маркеры изменения результата убираются из связанных терминов глоссария.
