# Имя конструкции — производная величина до ручного переименования

Смысловая основа конструкции проявляется по мере достройки ног (стреддл 1600 в протоколах трейдера собирался 48 дней), поэтому имя, зафиксированное при открытии, врёт для достроенных конструкций. Решено: имя пересчитывается из текущего состава живых опционных ног при каждом их изменении — включая инкрементную сборку и роллы — по лексике трейдера («стреддл с акцентом вверх 2:1», «колл-спред», «направленная CALL»); акцент отражает соотношение размеров ног и направление по доминирующей ноге. Ручное переименование фиксирует имя: признак в базе отключает автогенерацию для этой конструкции.

## Considered Options

- Имя при открытии окна (текущее поведение): дёшево, но имя навсегда описывает только первую ногу.
- Полностью ручное именование: не масштабируется при автоматической сборке.
