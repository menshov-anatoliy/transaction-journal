# Маркеры изменения результата: модель вкладов операций

> Статус: полностью superseded by [ADR-0024](0024-remove-finresult-result-history-markers.md) — маркеры изменения результата удалены: рендеринг, расшифровки, публикация в API и read-моделях, калькулятор вкладов.

Значение маркера изменения результата переформулировано из среза сводной формулы («С учётом зафиксированного синтетикой» + корректировки − входная стоимость открытых остатков, ADR-0021) в сумму вкладов операций: опционные окна — сумма сделок окна (ролл — выручка ликвидации старой позиции плюс стоимость новой), синтетическое закрытие — лок «зафиксировано синтетикой» со сменой знака при снятии/споре, фьючерсы — финансовый результат позиции, закрытой до нулевого остатка (round-trip по FIFO, с комиссиями), закрывающие записи — количество × эффективная цена, внешние корректировки PnL — сумма. Нулевой по факту вклад события не создаёт (OTM-экспирация исчезает из истории); ручная пометка считается по своей эффективной цене — иначе последний маркер расходился бы с реализованным результатом конструкции. Мотивация владельца (грилл-сессия 03.11.2026): результат должен прозрачно восстанавливаться из расшифровки подсказки метки, поэтому значение строится только из перечисляемых операций. Подпись бейджа метки — сумма самого изменения результата: изменением с предыдущей выведенной метки (первая — от нуля) вместо накопленного итога, тон подписи — по знаку изменения; бейдж стоит на накопленном итоге, а накопленный итог метки виден в заголовке её расшифровки. Расшифровка детализирует каждую операцию перечня компактными строками конкретных сделок: окна открытий, закрытий и роллов — сделки окна (инструмент, сторона, количество × цена, сумма вклада сделки; суммы сделок дают вклад операции), закрытие фьючерса — сделки цикла без индивидуальных сумм (вклад принадлежит round-trip целиком), поставка и ручное закрытие — инструмент и количество × эффективная цена, связки — период действия, корректировки — без детализации.

## Considered Options

- Сохранить модель среза сводной формулы: отвергнуто — значение не разлагается на краткий перечень операций, подсказка метки не сверяется сложением.
- Учитывать фьючерсные сделки по мере совершения (как в ADR-0021): отвергнуто — незакрытая фьючерсная позиция не является зафиксированным результатом, а её входная стоимость ошибочно вычиталась из истории.
- Ручная пометка с нулевым вкладом: отвергнуто — её эффективная цена (пользователя или последняя котировка) входит в реализованный результат; нулевой вклад навсегда разошёлся бы с итогом конструкции.
- Перечислять всю историю от нуля в каждой подсказке: отвергнуто — это не краткий перечень; цепочка «итог N−1 + Σ операций = итог N» прозрачна и компактна, подавленные порогом операции входят в расшифровку следующей выведенной метки.
- Оставить накопленный итог на подписи бейджа: отвергнуто — подпись изменением отвечает на вопрос «что дала эта метка», а накопленный итог восстанавливается из заголовка расшифровки и позиции бейджа на шкале.
- Индивидуальные суммы сделок фьючерсного цикла: отвергнуто — FIFO round-trip не разлагается на сделки без произвольных допущений, вклад принадлежит циклу целиком.
- Группировка однотипных операций в расшифровке: отвергнуто — перечень сверяется сложением построчно, свёртка «×N» скрывает суммы.

## Consequences

- Область описания маркеров под индикатором удаляется полностью (UI, design.pen, спеки, глоссарий); перечень операций живёт в подсказке каждой метки, включая последний маркер среднего и компактного видов.
- Контракты карточки, списка и превью публикуют перечень операций вместе с маркерами; порог 5% планового риска, безусловные первая/последняя метки и сплошная нумерация по выведенным (ADR-0021) не меняются.
- Подпись бейджа переносится с накопленного итога на сумму изменения (тон — по знаку изменения); накопленный итог виден в заголовке расшифровки метки, позиция бейджа на шкале остаётся на итоге.
- Операции перечня детализируются сделками: суммы сделок окна дают вклад операции, сделки фьючерсного цикла публикуются без индивидуальных сумм — вклад принадлежит round-trip целиком.
- ADR-0021 частично заменён: модель значения и область описания — настоящим ADR; правки кода и спек оформляются отдельным OpenSpec change.
