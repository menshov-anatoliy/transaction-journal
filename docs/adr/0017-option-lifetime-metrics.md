# Метрики времени жизни конструкции — биржевые греки и история снимков, UI-предупреждение отдельно от агента подсказок

Оценку времени жизни конструкции (временная/внутренняя стоимость, остаток суток до экспирации, дневной распад и его прирост) считаем только из фактических биржевых данных публичного эндпоинта tickers ([исследование](../research/bybit-api.md) §3): внутренняя стоимость — `max(0, underlyingPrice − strike)` для колла и зеркально для пута, временная — `markPrice − внутренняя`, дневной распад ноги — биржевая тета × чистый остаток, саммари конструкции — нетто-сумма по открытым опционным ногам; собственной модели распада нет. Прирост распада — фактическая разность текущей теты с ближайшим снимком возрастом ≥ 24 ч из новой append-only истории рыночных снимков (символ, котировка, индекс, тета, момент), которая пишется при каждом свежем запросе тикеров (загрузка метрик UI, проход агента) без отдельного расписания и без очистки — историю невозможно восстановить задним числом, поэтому копится с первого дня. Предупреждение об экспирации — чисто временнОе: остаток полных суток до `deliveryTime` (floor, UTC) ≤ 14 у открытой опционной ноги открытой конструкции; живая индикация в существующем канале предупреждений конструкции (секция на карточке, бейдж «⚠ N» в списке, подсветка строки ноги, красный остаток дней), по одной строке на инструмент; фьючерсные ноги в метриках времени жизни не участвуют. Канал сознательно не сливается с агентом подсказок: правило ac-31 (`atm-decay-window`, время + цена в зоне страйка) остаётся в корпусе правил и срабатывает по своему триггеру ([ADR-0007](0007-hints-agent-architecture.md)). Ошибки рыночных данных (нет тикера, нет истории) не показываются — в соответствующей ячейке прочерк.

## Considered Options

- Собственная модель распада или проекция кривой теты вперёд — отклонена: прогноз, противоречит правилу журнала «никаких прогнозов, только действия по факту совершившихся событий».
- Хранить только последний снимок или пару «сегодня/вчера» — отклонено: прирост распада требует сравнения со снимком ≥ 24 ч назад, а история снимков не восстанавливается задним числом.
- Отдельный фоновый снапшоттер по расписанию — отклонён: лишний таймер в едином exe ([ADR-0003](0003-stack-single-exe-dotnet-sqlite.md)); записи и так создаются при каждом чтении метрик.
- Доставка предупреждения об экспирации сводкой агента подсказок — отклонена: живая индикация видна всегда при открытии журнала и не зависит от расписания проходов; условие «в зоне страйка» остаётся отличительной частью правила ac-31.
- Канал ошибок рыночных данных (нет тикера, устаревший снимок, незакрытая позиция после экспирации) — отклонён владельцем: за исключением случаев с прочерком.
