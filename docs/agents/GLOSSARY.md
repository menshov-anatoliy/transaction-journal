# Агентский цикл разработки

Словарь процесса, которым идея доработки журнала доводится от черновика до передачи агенту-исполнителю. Отделён от продуктового словаря журнала сделок.

## Language

**Черновик идеи**:
GitHub Issue по шаблону идеи, созданный владельцем: проблема, желаемый результат, ограничения. Входная точка цикла.
_Avoid_: «тикет», «заявка», «драфт»

**Трек**:
Маршрут, по которому черновик идеи доводится до передачи агенту; выбирается на triage. Бывает трёх видов: срез, спека, карта.
_Avoid_: «поток», «размер задачи»

**Срез**:
Узкая вертикальная доработка, проходящая все слои, проверяемая сама по себе и умещающаяся в одно окно контекста агента. Единица передачи агенту.
_Avoid_: «подзадача», «таск»

**Спека**:
Трек, в котором черновик идеи формализуется в отдельный issue-спеку, а она делится на срезы со связями блокировки.
_Avoid_: «эпик», «фича»

**Карта**:
Трек для идеи с неразрешёнными неизвестными: сначала снимаются решения и исследования, затем идея переходит в спеку.
_Avoid_: «роадмап», «исследование»

**Бриф агента**:
Комментарий к issue, который является контрактом среза для агента-исполнителя: поведение, критерии приёмки, границы охвата. Тело issue остаётся контекстом.
_Avoid_: «описание задачи», «ТЗ»

**Готовность к передаче**:
Состояние среза, при котором он удовлетворяет чек-листу готовности и владелец подтвердил передачу агенту.
_Avoid_: «готово», «approved», «Definition of Done»

**Сессия опроса**:
Отдельная синхронная агентская сессия, в которой владелец отвечает на вопросы по одному issue; по её итогам issue переходит в следующее состояние.
_Avoid_: «async-опрос», «обсуждение в комментариях»
