# Скриншот-сверка 3.1 — каркас `AppLayout` (Каркас)

Приёмка задачи 3.1 change `reconcile-frontend-with-design` по процессу
design.md D3: пара «макет/страница» для фрейма «Каркас» (g0z20, 1440×620)
по расхождениям §3.1 аудита: 1 (топбар), 2 (нав-пункты), 4 (бейдж «Входящие»).

Процесс: макет — экспорт ноды `g0z20` из design.pen через MCP pen (`Export`
png 2×) + `Get(jGvOM/t4nFb/bKXol/Vx9C2/apcZH/q35Tj9/FQT4Y/IdwN5)` для
авторитетных значений; страница — живой рендер `http://localhost:5173/spa/`
(Vite) в headless Chrome 1440×620 через CDP: computed-стили и PNG. Счётчик
«Входящие» для отрисовки бейджа закрыт CDP-перехватом `GET /api/v1/inbox/count`
→ `{"count":12}` (значение инстанса мастера bKXol); бэкенд не поднимался.
Дополнительная объективная проверка — пиксельный сэмплинг обоих PNG.

## Файлы пары

- `design-frame.png` — «Каркас» g0z20 из design.pen (2×, 2880×1240).
- `app-page.png` — живая страница «Конструкции» (1440×620), бейдж = 12.
- `app-badge-clip.png` — прицельный клип бейджа «Входящие» (2×) страницы.

## Отклонения от текста задачи 3.1 — решение по мастер-нодам

1. **Высота топбара 54, а не 52.** Текст задачи (и аудит §3.1) «52px» берёт
   высоту фрейма `IdwN5` (h=52, [0,16], burger-иконка) — другого reusable
   топбара, в «Каркасе» g0z20 не используемом. Фактический топбар «Каркаса» —
   нода `jGvOM`: **h=54, [0,24]**, Logo+Brand+SyncStatus. Источник истины —
   мастер g0z20, поэтому взято 54/[0,24]; отклонение зафиксировано комментарием
   в `AppLayout.tsx`.
2. **Бейдж — заливка `$accent` + белый текст, а не пара accentSoft/accentStrong.**
   Прямое чтение нод: бейдж в «Каркасе» — инстанс `q35Tj9` внутри `apcZH`
   (bKXol → q35Tj9 enabled, content «12») и reusable `FQT4Y` «Бейдж/Число»:
   **fill `$accent` #1FA36B, текст #FFFFFF 11/600, pill 999, [2,8]**. Пара
   accentSoft #E2F4EB / accentStrong #167853 в «Каркасе» принадлежит логотипу
   топбара (`srW2i`: заливка accentSoft, иконка line-chart accentStrong), а не
   бейджу. Сделано по мастеру (дефолтный бейдж примитива `NavItem`:
   `bg-primary`/`text-primary-foreground` = $accent/белый), отклонение
   зафиксировано комментарием в коде. Наводка «пара у бейджа» из нахождения
   2.2 опровергнута повторным чтением нод.

## Расхождения вне зоны 3.1 — не исправлялись (рамка: пункты 1, 2, 4)

- Ширина панели: 256 (`w-64`) против 240 в t4nFb — §3.1:3, сверен визуально,
  правка не входит в задачу.
- В топбаре мастера есть Logo 26×26 (accentSoft/accentStrong, line-chart) и
  SyncStatus «Синхронизировано · 13:42» (11.5 $textMuted) — в приложении их
  нет; SyncStatus и иконки явно исключены рамкой задачи.
- Кнопка «Свернуть» в приложении — ghost-иконка в топбаре; в дизайне — внизу
  панели (нода eMdVl «Collapse», [8,10], r8).
- Подпись «РАЗДЕЛЫ» (10, letterSpacing 0.6, $textMuted) над пунктами панели
  мастера не перенесена: не входит в пункты 1/2/4.
- Отступ 28 между топбаром и панелью на `design-frame.png` — композиция
  макета (панель — отдельный reusable-фрейм ниже топбара); в живом приложении
  панель примыкает вплотную (границы divider), на сверку зон не влияет.
