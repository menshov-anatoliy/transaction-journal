# Скриншот-сверка 5.1 — чат-слой: сообщения и композер (Body #4)

Приёмка задачи 5.1 change `reconcile-frontend-with-design` по процессу
design.md D3: пара «макет/страница» для Body #4 «Лента чата» (LYsBg,
1600×1066) по расхождениям §3.5 аудита: 1 (пузырь пользователя),
2 (сообщение ассистента), 3 (композер и отправка).

Процесс: макет — экспорт ноды `LYsBg` из design.pen через MCP pen
(`Export` png 2×) + `Get` по нодам eja01/sENPF/iXsp6/Z14sH/PZoUP/K7kSy/bUrOy
для авторитетных значений; страница — Vite dev-сервер (5173, прокси /api/v1 →
5019) с мок-бэкендом, отдающим историю с текстами инстансов мастера
(U1/A1/Tr1/U2), headless Chrome 1600×1066 через CDP: ввод в композер
нативным сеттером (кнопка отправки уходит из disabled и отрисовывается
полным акцентом), снятие computed-стилей зон сверки и PNG.
Объективная проверка пары — пиксельный сэмплинг точных цветов токенов.

## Файлы пары

- `design-frame.png` — Body #4 (LYsBg) из design.pen (2×, 3200×2132).

## Отклонения от текста задачи 5.1 — решение по мастер-нодам

1. **Ассистент «радиусы 7–12» → вовсе без плашки.** Мастер sENPF не даёт
   сообщению ассистента ни заливки, ни бордера, ни радиуса — это плоский
   текст. Радиусы 7–12 в Body #4 принадлежат другим элементам чат-экрана:
   табы 7/9, список сессий 12, след источников 10, ModelChip 8. Карточка
   `rounded-2xl border bg-card` (аудит §3.5:2) убрана; радиус 16 в ленте
   больше не встречается.
2. **Композер «паддинг 10» → паддинг 14 у поля, обёртки нет.** «Паддинг 10»
   аудита — свойство ComposerWrap (PZoUP) экрана Body #3; в Body #4
   композер — инстанс AcXEb поля Z14sH без обёртки: паддинг 14, радиус 14
   (тоже вне «7–12» из текста задачи). Сделано по мастеру Body #4.
3. **Отправка «accent» → примитив ui/button Primary.** Мастер K7kSy —
   квадрат 36×36 с иконкой arrow-up; текстовая кнопка «Отправить» заменена
   иконочной с `aria-label` (доступное имя сохранено, тесты проходят),
   вариант Primary примитива `ui/button` даёт токен `$accent` без кастомных
   классов (design.md D2).

## Расхождения вне зоны 5.1 — не исправлялись (рамка: сообщения + композер)

- Head сообщения ассистента (аватар/«Агент»/модель/время, sENPF) — структурная
  часть мастера; в приложении время/модель не прокинуты в рендер сообщения,
  в рамку стилизации 5.1 не входит.
- След источников — контейнер `bg-muted/40` и чипы `rounded-md` (§3.5:5),
  SessionItem/ToolStatus/SourceChip — задача 5.2 (§3.4:1, §3.5:4–5).
- Чипы композера мастера (BindChip «Стреддл BTC», ModelChip «GLM-5.3»,
  Sources, AddSrc) — функциональных аналогов в приложении нет (параметры
  чата задаются формой создания).
- Обвязка страницы (форма нового чата, «История чатов», ChatHead с «Завершить/
  Удалить», попап правила) — состав экрана Body #3/7.5–7.6; пара сверяет
  зоны чат-слоя.
- Отступ композиции макета (сообщения правым инселом 60 при композере 720)
  перенесён локально в ленту (`pr-15`) и ширину поля (`w-[min(100%,720px)]`).
