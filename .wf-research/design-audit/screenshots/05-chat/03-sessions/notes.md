# Скриншот-сверка 5.2 — Body #3: список сессий (SessionItem)

Приёмка задачи 5.2 change `reconcile-frontend-with-design` по процессу
design.md D3: пара «макет/страница» для Body #3 «Агент → Чаты» (PNErm,
1600×970) по расхождению §3.4:1 аудита (пункт сессии — inline-разметка
`li rounded-md border p-2` вместо компонента «Сессия/пункт»).

Процесс: макет — экспорт ноды `PNErm` из design.pen через MCP pen
(`Export` png 2×); страница — Vite dev-сервер (5173, прокси /api/v1 → 5019)
с мок-бэкендом (2 активные + 2 завершённые сессии), headless Chrome
1600×1066 через CDP, снятие computed-стилей зон сверки и PNG.
Объективная проверка пары — пиксельный сэмплинг точных цветов токенов.

## Файлы пары

- `design-frame.png` — Body #3 (PNErm) из design.pen (2×, 3200×1940).
- `app-page.png` — живая страница `/spa/agent` (1600×1066), вкладка «Чаты»,
  правая колонка «История чатов» с пунктами-сессиями.

## Отличия данных и рамки 5.2 (не исправлялись здесь)

- Заголовок пункта — модель чата (`params.model`: «GLM-5.3»): ChatDto
  чат-слоя не несёт вопрос-заголовок и превью последнего сообщения, как
  инстансы мастера («Стреддл BTC — оценка риска» + превью). Превью у
  примитива опционально и включится с появлением данных.
- Под пунктом остаётся служебная ссылка «Завершить/Продолжить чат» —
  поведение жизненного цикла чата; в мастере эти действия живут в ChatHead
  (jQFGN Finish/tsdFA Delete), ссылка в списке сохранена до редизайна списка.
- Контейнер «История чатов» и форма нового чата (радиусы/паддинги секций,
  поля, чекбоксы источников) — рамка задач §3.4:2–3 / 7.5, не тронуты.
