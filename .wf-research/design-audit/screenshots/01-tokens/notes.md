# Скриншот-сверка 1.3 — шов «токены + шрифты» (Каркас)

Приёмка задач 1.1–1.2 по процессу design.md D3: пара «макет/страница» для
фрейма «Каркас» (g0z20, 1440×620) после смены темы на дизайн-токены.

Процесс сверки: макет — экспорт ноды `g0z20` из design.pen через MCP pen
(`Export` png 2×) + `Get(jGvOM/t4nFb, depth 2)` для авторитетных значений;
страница — живой рендер `http://localhost:5173/spa/` (Vite) через
интегрированный браузер pen (`Emulation.setDeviceMetricsOverride` 1440×620,
снятие computed-стилей через CDP), PNG сохранён headless Chrome 1440×620.
Дополнительная объективная проверка — пиксельный сэмплинг обоих PNG.

## Файлы пары

- `design-frame.png` — «Каркас» g0z20 из design.pen (2×, 2880×1240).
- `app-page.png` — живая страница «Конструкции» под топбаром (1440×620).

## Вывод: шов выдержан

Расхождений в зоне задач 1.x (токены и шрифты) не найдено — кодовых правок
не потребовалось. Совпадения зафиксированы по computed-стилям живой страницы
и пиксельным сэмплам обоих скриншотов:

| Позиция | Дизайн (design.pen) | Страница (computed / пиксель) |
|---|---|---|
| Фон-подложка `$bg` | `#F3F3EF` (панель и подложка Каркаса) | `body` `rgb(243,243,239)` = `#F3F3EF` |
| Поверхность `$surface` | `#FFFFFF` (Топбар jGvOM) | `header` `rgb(255,255,255)` = `#FFFFFF` |
| Активный нав-пункт `$accentSoft` | `#E2F4EB` | `rgb(226,244,235)` = `#E2F4EB` |
| Текст активного пункта `$accentStrong` | `#167853` | `rgb(22,120,83)` = `#167853` |
| Основной текст `$textPrimary` | `#17171E` (Brand) | бренд `rgb(23,23,30)` = `#17171E` |
| Вторичный текст `$textSecondary` | `#66666E` | `--muted-foreground` → `#66666E` |
| Акцент `--primary` | `#1FA36B` | `--primary: #1FA36B` |
| Граница `$border` | `#E5E5DF` | `--border: #E5E5DF` |
| Шрифт | Inter (`$font`) | computed `font-family: Inter` (self-hosted woff2, D4) |
| oklch-остатки темы | — | греп `oklch|hsl(` по `index.css` пуст; `--fin-*` наследует токены |

Синий пиксель `#1751AA`, замеченный при сэмплинге топбара, — ClearType-субпиксель
на краю глифа «Ж» бренда (соседние пиксели `#17171E`), не индиго-остаток.

## Расхождения вне зоны 1.x — вход для задач 2–7 (не исправлялись)

Зона задачи 3.1 (каркас `AppLayout`):

1. Топбар: `h-14`/`px-4` и бренд 16/600 против дизайна 52px/`[0,24]` и 14/600
   (§3.1 отчёта: 1, 2).
2. В дизайн-топбаре есть Logo-маркер (`$accentSoft`) и SyncStatus
   «Синхронизировано · 13:42» (11.5 `$textMuted`) — в приложении отсутствуют.
3. Панель навигации: в дизайне `fill $bg` (`#F3F3EF`), в приложении
   `bg-card` (`#FFFFFF`) — применение слота, сам токен верен.
4. Иконки/лейблы каркаса в дизайне — `$textMuted` `#9B9BA1`, в приложении
   нав-иконки наследуют `text-muted-foreground` (`#66666E`, text-secondary).
5. Нав-пункты: `h-10`/`px-3`/`rounded-lg`/`text-sm` против `[8,10]`/радиус 8/
   11.5 (§3.1: 2) — закрывается примитивом `NavItem` (задача 2.2) и 3.1.
6. Кнопка «Свернуть» в приложении — иконка в топбаре; в дизайне — внизу
   панели с лейблом 12 `$textMuted`.
7. Бейдж «Входящие» — `bg-primary/15`; дизайн-примитив Бейдж/Число FQT4Y
   (на скриншоте не виден: API-бэкенд поднят не был, счётчик пуст).

Зона задачи 7.1: титул страницы 24px (`text-2xl`) против 21/600.
