# Proposal

## Why

Модель значения маркеров изменения результата (change `add-finresult-result-history-markers`, ADR-0021) считает значение срезом сводной формулы: результат не разлагается на прозрачный перечень операций, фьючерсные сделки учитываются до закрытия позиции (входная стоимость незакрытого фьючерсного остатка ошибочно вычитается), а область описания маркеров дублирует подсказку. Переработано с владельцем в грилл-сессии 03.11.2026, зафиксировано в ADR-0022 и глоссарии (термины «Вклад операции», «Расшифровка маркера»).

## What Changes

- **BREAKING** (в пределах контрактов change-цикла): модель значения маркеров переформулируется на сумму вкладов операций: открытие и закрытие опционных позиций — сумма сделок окна; ролл — выручка ликвидации старой позиции плюс стоимость новой (сумма сделок окна); синтетическое закрытие — лок «зафиксировано синтетикой» (активация — плюс, снятие/спор — минус, автоснятия при реальном закрытии нет); фьючерсы — финансовый результат позиции, закрытой до нулевого остатка (round-trip по FIFO, с комиссиями); закрывающие записи — количество × эффективная цена (ручная пометка — по цене пользователя/котировке); внешние корректировки PnL — сумма.
- Фьючерсные операции дают события только для закрытых сделок: есть открывающие и закрывающие, нулевой остаток; частичные закрытия и чистые открытия событий не создают.
- Нулевой по факту вклад события не создаёт: OTM-экспирация и записи без эффективной цены исчезают из истории.
- Контракты карточки, списка и превью публикуют перечень операций `operations[]` (вид, дата, сумма вклада) вместе с маркерами и последним маркером; подавленные порогом операции входят в перечень следующего выведенного маркера.
- **Удаляется область описания маркеров** под индикатором (UI, design.pen, спеки, глоссарий); взамен каждая метка получает подсказку-расшифровку: краткий перечень операций с предыдущего выведенного маркера, включая подавленные; сумма перечня = изменение, «итог N−1 + сумма перечня = итог N»; без группировки, с прокруткой при переполнении. Подсказка доступна и на последнем маркере среднего и компактного видов.
- Попап «Как читать индикатор» переписывается под модель вкладов (по ADR-0022, без формулировок среза сводной формулы).
- Без изменений: порог проявления 5% планового риска, безусловные первая/последняя метки, сплошная нумерация по выведенным, вычисление на лету без хранения, маркер текущего результата, состояния риска, нейтральная полоса без маркеров при незаданных плановых параметрах.

## Capabilities

### New Capabilities

(нет — изменения укладываются в существующие возможности)

### Modified Capabilities

- `analytics/performance`: переформулируются `requirement-result-markers-history-events` (фьючерсы только при нулевом остатке; снятие связки — отдельное событие с реверсом лока; закрывающие записи — только с денежным потоком), `requirement-result-marker-value` (сумма вкладов операций вместо среза сводной формулы), `requirement-result-markers-contract` (публикация `operations[]`); `requirement-result-marker-threshold` не меняется.
- `ui/screens`: из `requirement-risk-profit-hint` уходит область описания, добавляется подсказка-расшифровка меток (включая последний маркер среднего и компактного видов); обновляются `requirement-indicator-reading-tooltip` (текст по ADR-0022) и `requirement-indicator-numbers-tooltips-alongside-reading-popover` (подсказка суммы метки становится расшифровкой).
- `ui/design-system`: `requirement-design-finresult-result-markers` — из макета удаляется область описания, добавляется изображение подсказки-расшифровки; `requirement-design-card-reading-tooltip` — текст попапа по ADR-0022.

## Impact

- **design.pen** (правка первой, строго через MCP Pen, по ADR-0011): удалить область описания маркеров (оба состояния), изобразить подсказку-расшифровку бейджа (перечень операций), обновить текст попапа «Как читать индикатор».
- Backend: `ConstructionResultMarkersCalculator` (модель вкладов вместо среза, фьючерсы по нулевому остатку, реверс лока, вклад закрывающих записей), `ResultMarkerJournalMaterial`, `ConstructionResultMarkersReader`, `ConstructionResultMarkers`/`ConstructionDetailRows`/`ConstructionListRows` (контракты `operations[]`), API-эндпоинты карточки/списка/превью.
- Frontend: `fin-result-indicator.tsx` (удаление `MarkerDescriptionArea`, подсказки-расшифровки на бейджах и последнем маркере), `metric-tooltips`, компонентные тесты.
- Документация: GLOSSARY.md и ADR-0022 уже обновлены в грилл-сессии; ADR-0021 помечен частично заменённым.
- Порядок: перед применением change архивируется `add-finresult-result-history-markers` как есть — дельты этого change рассчитаны на пост-архивное состояние основных спек.
