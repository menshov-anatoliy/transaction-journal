# Proposal

## Why

Чат, начатый из карточки конструкции, нельзя найти в общем списке чатов на форме агентов: пункт списка показывает только модель и время (привязка к конструкции не видна), список упорядочен по возрастанию Id (новые чаты внизу), фильтра по привязке нет. Проверено на данных: чат 38 (`ConstructionId = 8`, статус Active) присутствует в ответе `GET /api/v1/chats?status=active`, но среди 52 пунктов «glm-5.3 + время» его невозможно опознать. Отклонение уже помечено в change `fix-agent-chat-activity` (задача 5.1): «превью в пункте сессии не рендерится (нет данных в ChatDto)».

## What Changes

- **Признак привязки на пункте сессии** (фронт): чат с привязкой показывает имя конструкции (резолвится клиентом из существующего обзора конструкций по `params.constructionId`); портфельные чаты остаются без бейджа.
- **Превью первого сообщения** (бэкенд): список чатов дополняется текстом первого сообщения владельца — `ChatDto` получает поле превью; без него пункты списка остаются неразличимыми даже с бейджем.
- **Свежесть сверху** (фронт): список сессий упорядочивается по моменту последнего сообщения, самые свежие — вверху группы.
- **Разделение по привязке** (фронт): на форме агентов чаты разделяются на портфельные и привязанные к конструкциям (группы или фильтр), чтобы чат конструкции искался в коротком списке, а не в общем.

## Capabilities

### New Capabilities

_None_

### Modified Capabilities

- `chats/history`: новое требование к представлению списков чатов — список несёт опознавательные данные (превью первого сообщения владельца) помимо параметров и статуса.
- `ui/screens`: новое требование к форме агентов — список сессий опознаваем (имя конструкции, превью, свежесть сверху) и разделяется по привязке; панель «Консультации» карточки не меняется.

## Impact

- `src/TransactionJournal/Api/Agent/AgentEndpoints.cs` (`BuildChatDtoAsync`) — поле превью в списковом DTO; `src/TransactionJournal.Chats` (`ChatService`, порт `IChatStore`) — чтение первого сообщения владельца при перечислении; схема БД не меняется (превью вычисляется из истории при выдаче).
- `frontend/src/pages/agent-page.tsx` (`ChatList`, `SessionItem`) — бейдж конструкции, превью, сортировка по свежести, разделение по привязке; `frontend/src/chat/types.ts` — поле превью в `ChatDto`.
- Порядок: независимо от `fix-agent-chat-activity`; перенимает его открытое отклонение из задачи 5.1.
