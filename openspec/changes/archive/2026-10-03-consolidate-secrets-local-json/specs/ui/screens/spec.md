# Spec Delta

## MODIFIED Requirements

### Requirement: Экран «Настройки» — подключение, синхронизация, переразбор
Экран SHALL показывать параметры подключения: маскированный API-ключ, тип аккаунта и место хранения секрета — локальный файл `appsettings.Local.json`; секрет SHALL не отображаться и не вводиться через интерфейс. Синхронизация SHALL запускаться единственной кнопкой «Синхронизировать сейчас»; выбранный системой режим SHALL быть виден в журнале синхронизаций с временем, результатом, статусом и предупреждениями сверки. Экран SHALL содержать переключатель резервного копирования перед синхронизацией, включённый по умолчанию: пока он включён, синхронизация не начинается до успешного создания копии (правила копии — capability `ops/db-backup`). Команда «Переразобрать сырые записи заново» SHALL требовать подтверждения.

Traceability ID: requirement-settings-screen

#### Scenario: Секрет не отображается на экране настроек
Traceability ID: scenario-settings-secret-never-displayed
- **WHEN** пользователь открывает «Настройки»
- **THEN** API-ключ показан маскированно, а секрет не отображается нигде
- **AND** экран указывает appsettings.Local.json как место хранения секрета

#### Scenario: Журнал синхронизаций показывает режим и предупреждения
Traceability ID: scenario-settings-sync-log-mode-warnings
- **WHEN** синхронизация завершается
- **THEN** в журнале появляется строка со временем, выбранным системой режимом, результатом и статусом
- **AND** предупреждения сверки с биржей показываются в журнале, не блокируя работу

#### Scenario: Переразбор требует подтверждения
Traceability ID: scenario-settings-reparse-confirmation
- **WHEN** пользователь нажимает «Переразобрать сырые записи заново»
- **THEN** приложение требует явное подтверждение опасного действия
- **AND** без подтверждения переразбор не запускается

#### Scenario: Выключенный переключатель запускает синхронизацию без копии
Traceability ID: scenario-settings-sync-backup-toggle
- **WHEN** пользователь выключает переключатель резервного копирования и нажимает «Синхронизировать сейчас»
- **THEN** синхронизация запускается без создания резервной копии
