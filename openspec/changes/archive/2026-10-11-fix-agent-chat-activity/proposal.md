# Proposal

## Why

Чат агента не отвечает на запросы и не показывает активность: SSE-протокол бэкенда (`start/token/done/error`) не сообщает о вызовах инструментов, поэтому на время tool-вызовов UI «молчит»; отказы генерации (ненастроенный `Llm:ApiKey`, недоступный BaseUrl провайдера, ошибка модели) приходят только error-кадром при HTTP 200 и не диагностируются. Дизайн чата и композера отстаёт от design.pen (change `revise-design-screens` обновляет первоисточник), чаты карточки конструкции живут в фиксированной панели `w-96 h-[32rem]`, а не в контекстной панели каркаса (change `rework-spa-shell-and-screens`). Решения — grilling-сессия 2026-10-10 (Q9, Q12–Q16).

## What Changes

- **Диагностика и фикс «чат не отвечает»**: воспроизвести молчание, найти и устранить причину (ключ `Llm:ApiKey`, BaseUrl, имя модели, исключения генерации); логировать причину отказа на бэкенде; критерий — любой отказ генерации виден в UI баннером с человеческой причиной.
- **Активность агента в протоколе**: SSE-стрим дополняется событиями `tool` (имя инструмента, фаза start/end); UI показывает живые пилюли ToolStatus по этим событиям вместо статичной надписи.
- **Чаты карточки в контекстной панели**: панель чатов переезжает из фиксированной `w-96 h-[32rem]` в контекстную правую панель каркаса — на всю высоту контента, resizable/сворачиваемая, на карточке развёрнута по умолчанию.
- **Композер по практикам**: многострочное autorost-поле (~1–8 строк), Enter — отправка, Shift+Enter — перенос, кнопка отправки заблокирована при пустом вводе, Stop во время генерации, чипы (привязка, модель, источники) — тулбаром под полем.
- **Дизайн чата по design.pen**: сообщения, tool-статусы, след источников, пункты сессий — скриншот-сверка с обновлённым первоисточником.

## Capabilities

### New Capabilities

_None_

### Modified Capabilities

- `http-api/transport`: SSE-стрим чата дополняется событиями активности инструментов; требование к доставке причины ошибки усиливается.
- `ui/screens`: панель чатов в деталях конструкции — контекстная панель каркаса, живые статусы инструментов, композер по практикам ввода.

## Impact

- `src/TransactionJournal/Api/Sse/ChatSseStream.cs`, `ChatStreamEvent.cs`, `Api/Agent/AgentEndpoints.cs`, `src/TransactionJournal.Chats` (`ChatAgent`, `ChatService`) — события `tool`, логирование причин отказов.
- `frontend/src/chat/*` (runtime, `agent-chat-thread.tsx`), `frontend/src/components/constructions/card/construction-chats-panel.tsx` — обработка событий, пилюли активности, композер, переезд в контекстную панель (слот из change'а `rework-spa-shell-and-screens`).
- Порядок: после `revise-design-screens` (первоисточник) и `rework-spa-shell-and-screens` (механика контекстной панели).
