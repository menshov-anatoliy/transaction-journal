# Proposal

## Why

Термин «марка» (mark price) конфликтует с обыденными значениями и вытесняется каноничным «котировка»: пользователь попросил полностью убрать слово «марка» из проекта. Единый термин снимает путаницу между биржевой оценкой инструмента, «ручной пометкой закрытия» (`ManualCloseMark`) и «маркером итога» индикатора финрезультата, которые сегодня соседствуют в одних и тех же интерфейсах.

## What Changes

- **BREAKING**: поле внутреннего HTTP/JSON-контракта `markPrice` переименовывается в `quotePrice` (ответы API и TS-типы фронтенда поставляются вместе, внешних потребителей нет).
- Идентификаторы C#/TS с корнем `Mark` переименовываются на `Quote`/`Quotation`-основу: `InstrumentMarkProvider` → `InstrumentQuoteProvider`, `UnrealizedPnlMarkEvaluator` → `UnrealizedPnlQuoteEvaluator`, `IMarkSource` → `IQuoteSource`, `HintsMarkSource` → `HintsQuoteSource`, `ManualCloseMark` → `ManualCloseAnnotation` (это пользовательская пометка закрытия, а не цена; английское имя перестаёт конфликтовать с mark price) и остальные по карте из design.md.
- Русские тексты (комментарии кода, XML-док, UI-надписи и тултипы, глоссарий, документация, живые specs) переводятся с «марки/марок/марку…» на «котировки/котировок/котировку…»; слова «маркер» (маркер итога) и «маркировать» (разметка) не термин «марка» и не меняются.
- Именование внешнего API Bybit не меняется: wire-поле биржи `markPrice` остаётся `markPrice` в маппинге внешнего ответа — переименовываются только внутренние DTO и контракт журнала.
- SQLite-колонки с `MarkPrice` переименовываются новой EF-миграцией; исторические файлы миграций не переписываются.
- `design.pen` обновляется строго через MCP Pen до правки фронтенда: тексты макета («подставлена последняя марка инструмента», «открытый остаток по текущим маркам…») переходят на «котировку».
- Поведение системы не меняется: ни один расчёт, статус или сценарий не затрагивается — меняются имена, тексты и контрактное поле.

## Capabilities

### New Capabilities

- _нет_

### Modified Capabilities

- `analytics/performance`: формулировки требований о нереализованном PnL, провайдере котировок, метриках позиции/конструкции, реальном риске, агрегатах, стоимости и проценте изменения цены переводятся на термин «котировка» (8 требований).
- `analytics/option-lifetime`: история рыночных снимков и разложение стоимости опционной ноги — «котировка» вместо «марки» (2 требования).
- `chats/sources`: деградация рыночного инструмента в кэш с as-of — «кэш котировок» (1 требование).
- `domain/constructions`: ручная пометка закрытия по умолчанию подставляет последнюю котировку (1 требование).
- `domain/synthetic-close`: независимость паритетного лока и сводной величины от сбоя котировок (2 требования).
- `hints/engine-pass`: проход движка по журналу, котировкам и корпусу (3 требования).
- `sync/bybit-history`: описание `markPrice` исполнения заменяется на «котировка на момент исполнения» (1 требование).
- `ui/screens`: топбар, списки, детали, пометка закрытия, индикатор финрезультата, запуск прохода — «котировки» в формулировках и сценариях (7 требований).

## Impact

- **`design.pen`** (первым шагом, строго через MCP Pen): тексты макета с «маркой» → «котировка»; затем перенос во фронтенд и скриншот-сверка.
- **Бэкенд C#**: переименование типов/членов/файлов (`*Mark*` → `*Quote*`, `ManualCloseMark*` → `ManualCloseAnnotation*`), JSON-поле `markPrice` → `quotePrice` в ответах эндпоинтов, XML-док и комментарии.
- **БД**: новая EF-миграция переименования колонок `MarkPrice` → `QuotePrice` в SQLite; существующие миграции не трогаются.
- **Фронтенд TS/React**: TS-типы и маппинги `markPrice` → `quotePrice`, тексты UI и тултипов.
- **Specs**: живые specs обновляются дельтами этого change при sync/архивации; параллельный активный change `add-summary-channels` правится точечно («время рыночных марок» → «время рыночных котировок»), т.к. его дельта ещё не синхронизирована.
- **Документация**: `GLOSSARY.md` (запись «Котировка», разграничение с last price и «валютой котировки»), `docs/research/bybit-api.md` (русские формулировки; внешние поля Bybit не меняются), ADR-0019 «Котировка вместо марки» — создан в сессии планирования.
- **Не трогается**: `openspec/changes/archive/**`, `.wf-research`, wire-поля Bybit, слова «маркер»/«маркировать», Traceability ID (стабильные идентификаторы, включая исторические `mark`-корни).
