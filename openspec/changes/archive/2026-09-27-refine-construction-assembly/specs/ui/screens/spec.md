# Spec Delta

## MODIFIED Requirements

### Requirement: Настройки — сборка конструкций
Экран «Настройки» SHALL содержать две команды сборки. Команда «Собрать из „Входящих"» выполняет инкрементную сборку нераспределённых записей и SHALL запускаться без диалога подтверждения. Команда «Собрать конструкции» выполняет полный пересбор; её запуск SHALL требовать подтверждения с явным перечнем безвозвратных потерь: все конструкции, привязки сделок, выделенный капитал, риск и профит, комментарии конструкций, позиций и сделок, внешние корректировки PnL и ручные пометки закрытия. После завершения каждой команды SHALL отображаться итог: число созданных конструкций, число привязанных сделок и число сделок, оставшихся во «Входящих». Результат сборки SHALL отражаться в списке конструкций и бейдже «Входящих» без дополнительных действий пользователя.

Traceability ID: requirement-settings-assembly-action

#### Scenario: Подтверждение перед пересборкой
Traceability ID: scenario-assembly-requires-confirmation
- **WHEN** пользователь нажимает «Собрать конструкции»
- **THEN** система показывает подтверждение с перечнем безвозвратных потерь
- **AND** пересборка не запускается до явного подтверждения

#### Scenario: Сборка из «Входящих» запускается без подтверждения
Traceability ID: scenario-inbox-assembly-without-confirmation
- **WHEN** пользователь нажимает «Собрать из „Входящих"»
- **THEN** инкрементная сборка запускается сразу, без диалога подтверждения

#### Scenario: Итог пересбора показывается пользователю
Traceability ID: scenario-assembly-shows-result
- **WHEN** сборка из «Входящих» или полный пересбор завершилась
- **THEN** пользователь видит счётчики созданных конструкций, привязанных сделок и сделок во «Входящих»
