# Design

## Context

Аудит (`.wf-research/design-audit/report.md`) установил корневую причину дрейфа: тема `frontend/src/index.css` — самостоятельная shadcn-палитра (индиго, oklch), написанная по текстовой концепции до появления `design.pen`; токен-слой и библиотека примитивов не создавались. Стек: Tailwind CSS 4 CSS-first (тема целиком в `index.css`, отдельного `tailwind.config.*` нет), shadcn/ui new-york (3 компонента), фининдикатор уже на токенах `--fin-*` 1:1 — эталон механики переноса. Решения сверки зафиксированы в ADR 0011 и grill-сессии (Q1–Q13).

## Goals / Non-Goals

**Goals:**

- Перенести 24 дизайн-токена в тему SPA и подключить Inter/JetBrains Mono.
- Создать библиотеку примитивов, эквивалентную reusable-компонентам design.pen.
- Привести 9 экранов к токенно-компонентному соответствию с приёмкой скриншот-сверкой.

**Non-Goals:**

- Функциональные изменения экранов (состав, маршруты, данные — на месте).
- Изменение `design.pen`; мобильные оверлеи и `/Error` (вне дизайна).
- Визуальная регрессия в CI — отдельное решение после сверки (Q3).

## Decisions

### D1. Токены — hex-значения в `index.css`, маппинг на shadcn-семантику

24 переменные переносятся как есть (hex), без oklch-конверсии: значения дизайн-системы уже hex, конверсия искажает цветопередачу. Семантические слоты shadcn (`--primary`, `--destructive`, `--secondary`, `--muted` и т.д.) перенаправляются на дизайн-токены (`--primary` → accent, `--destructive` → neg, фон/карточки → bg/surface/surface2), плюс прямые переменные (`--risk`, `--info` и пары `*Soft`). Блок `--fin-*` сохраняется, наследуя значения токенов. Альтернатива — отдельный `tokens.css` — отклонена: конвенция проекта держит тему в одном файле.

### D2. Примитивы — в `frontend/src/components/design/`, поверх shadcn

Новые: `StatusChip` (Чип/Статус), `SourceChip` (Чип/Источник, pill 999), `Metric` (Метрика), `SessionItem` (Сессия/пункт), `ToolStatus` (Tool-статус), `NavItem` (Нав-пункт). Существующий `ui/button.tsx` ретемизируется (радиус 8, 13/500, варианты Primary/Secondary/Ghost/Danger на токенах). Инлайн-разметка страниц заменяется вызовами примитивов точечно (Q7). Альтернатива «переписать ui-кит с нуля» — отклонена: нарушает Q7 и ADR 0010.

### D3. Скриншот-сверка — MCP pen против живой страницы

Прогрев Vite dev-сервера → `pencil-browser load-page http://localhost:<port>` → `return-screenshot`; макетная сторона — экспорт экрана из design.pen через `Export`/`TakeScreenshot`. Пары сохраняются в `.wf-research/design-audit/screenshots/<task-id>/`. Детали компонентов берутся `Get(nodeId, {depth})` через MCP pen (аудит §7.1).

### D4. Шрифты — self-hosted woff2 + `@font-face`

Inter (основной) и JetBrains Mono (редактор) подключаются локальными файлами в `frontend/src/assets/fonts/`: журнал — локальный персональный инструмент (ADR 0003/0010), работа без сети — норма. Google Fonts `<link>` отклонён из-за сетевой зависимости.

### D5. MD-редактор — CSS-тематизация `@uiw/react-md-editor`

Переопределение CSS-переменных виджета и обёртка под дизайн-фреймы Header/Toolbar/Split/Footer (тулбар радиус 8, моно JetBrains Mono, кнопки Footer на примитивах). Замена редактора — эскалация (ADR 0010, план Б), не план А.

### D6. Таблицы — варианты плотности в общем слое

Общий слой таблиц получает варианты поэкранных паддингов (9/10, 7/12, 8/10, 6/12) и шрифта (12/11.5) вместо единого `p-2`; `inbox-page` переводится с сырой HTML-таблицы на общий слой.

### D7. Порядок работ — порядок аудита, шов блокирует страницы

Токены → примитивы → каркас → таблицы → чат → редактор → доводка → чистка. Каждый уровень принимается скриншот-сверкой до перехода к следующему.

## Risks / Trade-offs

- [Hex-токены рядом с oklch-остатками shadcn дают неполное перекрытие] → сверка оттенков по скриншотам; полный отказ от oklch-остатков в рамках D1.
- [`@uiw` может не поддаться полной тематизации] → эскалация на план Б ADR 0010 в таске редактора, решение фиксируется в change.
- [Ретемизация `ui/button.tsx` задевает все страницы разом] → таски 1–2 принимаются сверкой каркаса и примитивов до постраничной доводки.
- [Точечный патч рисует пропущенные места] → финишная чистка (таск 8) с грепом вне-токенных классов (`amber-`, `bg-primary/` индиго-остатки, `font-mono` вне редактора).
