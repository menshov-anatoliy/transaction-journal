# Proposal — Сверка frontend с дизайн-системой design.pen

## Why

Перенос дизайна из `design.pen` при строительстве SPA (карта [#50](https://github.com/menshov-anatoliy/transaction-journal/issues/50), change `rebuild-frontend-spa`) выполнен с систематическим дрейфом. Аудит (`.wf-research/design-audit/report.md`, факты — из MCP-экстракта `.wf-research/design-audit/design-extract.json`) показал расхождения на 9 из 9 экранах: тема `frontend/src/index.css` построена на дефолтной shadcn-палитре с индиго-акцентом вместо 24 дизайн-токенов design.pen (зелёный акцент `#1FA36B`, тёплая серая гамма), Inter не подключён, 5 из 26 дизайн-компонентов отсутствуют, ~10 существуют инлайн в страницах. Корневая причина — отсутствие механики переноса: не создан токен-слой и библиотека примитивов, поэтому каждая страница дрейфует самостоятельно.

## What Changes

- **Токен-слой**: 24 переменные design.pen переносятся в `frontend/src/index.css` (Tailwind 4 `@theme`/CSS-переменные: фоновая триада, границы, текстовые, зелёный акцент ×4, пары risk/neg/info); подключаются шрифты Inter и JetBrains Mono (для MD-редактора).
- **Примитивы**: создаются переиспользуемые компоненты Кнопка/{Primary,Secondary,Ghost,Danger}, Чип/Статус, Чип/Источник, Метрика, поля ввода, Нав-пункт — по дизайн-системе; `ui/button.tsx` переводится с шадсновских стилей на токены.
- **Каркас**: `AppLayout` — топбар 52px/px-24, бренд 14/600, активный нав-пункт на паре accentSoft/accentStrong, бейдж «Входящие» на токенах.
- **Слой таблиц**: общая дизайн-геометрия ячеек (поэкранные паддинги 9/10, 7/12, 8/10, 6/12; шрифт 12/11.5); сырая HTML-таблица `inbox-page.tsx` переводится на общий слой.
- **Чат-слой**: Сообщение/Пользователь (surface2, радиус 12, 13.5px — вместо индиго-пузыря), Композер/Агент, Сессия/пункт, Tool-статус (индикация tool-вызовов), След источников на чипах радиуса 999.
- **MD-редактор**: `@uiw/react-md-editor` тематизируется CSS под дизайн-фреймы Header/Toolbar/Split/Footer (тулбар радиус 8, JetBrains Mono); замена редактора — эскалация, не план А (ADR 0010).
- **Пер-страничная доводка**: титулы 21/600 (вместо 24), шапка итога (18/600, `[14,16]`, accentStrong), опасная зона на neg/negSoft/risk/riskSoft, карточки правил с пилюлями-атрибутами.
- **Чистка вне-токенных значений**: Tailwind-amber → risk/riskSoft; хардкоды фининдикатора — на токены (минор-заливка → riskZone); подпись сверхприбыли — точный хардкод с комментарием и записью в backlog дизайна.
- **Критерий приёмки**: токенно-компонентное соответствие (ADR 0011); каждый пер-страничный/послойный таск принимается скриншот-сверкой живой страницы с design.pen через MCP pen; evidence коммитится в `.wf-research/design-audit/screenshots/`.

## Capabilities

### New Capabilities

- `ui/design-system`: соответствие визуального слоя SPA дизайн-системе `design.pen` — перенос дизайн-токенов, типографика, переиспользуемые примитивы, геометрия экранов и приёмка скриншот-сверкой через MCP pen.

### Modified Capabilities

Не изменяются: функциональный состав экранов соответствует концепции (аудит §8), требования `ui/screens` не затрагиваются — меняется только стилевой/примитивный слой.

## Impact

- Код: `frontend/src/index.css` (тема), `frontend/src/components/**` (примитивы, каркас), `frontend/src/pages/**`, `frontend/src/chat/**`, `frontend/src/components/markdown/**`; зависимостей не добавляется (шрифты — подключение, `@uiw` — CSS-тематизация).
- `design.pen` не изменяется (заморожен на время сверки, ADR 0011); чтение дизайна — только через MCP pen.
- Вне масштаба (в design.pen отсутствуют): мобильные оверлеи `bg-black/40`, страница `/Error` — не трогаются.
- Работа ведётся в ветке `spec/rebuild-frontend-spa` без PR; коммиты Conventional Commits с `refs #50`.
