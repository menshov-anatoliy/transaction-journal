# Proposal

## Why

Единственный реальный запуск синхронизации 2026-09-22 выгрузил linear-историю целиком (1725 исполнений), но по категории option — только 2 исполнения BTC за февраль, при активной торговле опционами ETH и XAUT в апреле–сентябре. Причина: `OptionBaseCoinSource` строит перечень базовых активов доски непрофильтрованным запросом `GET /v5/market/instruments-info?category=option`, а биржа без параметра `baseCoin` отдаёт перечисление только одной доски по умолчанию (BTC; живая проверка 2026-09-23: 854 инструмента, курсор исчерпан), тогда как доски ETH (714 инструментов) и XAUT (408) видны только с явным `baseCoin`. Области этих досок не строятся вообще, их история исполнения не запрашивается, сделки молча отсутствуют во «Входящих». Требование `requirement-option-base-coin-coverage` опирается на ложную посылку «публичный справочник перечисляет все доски» — сам справочник этим свойством не обладает.

## What Changes

- Перечень областей прохода option строится объединением независимых источников: один безфильтровый проход истории исполнения категории (биржа отдаёт без фильтра записи всех активов аккаунта — проход и загружает записи, и обнаруживает активы), базовые активы записей сырьевого хранилища (исполнения и delivery-записи), живое перечисление справочника (доска по умолчанию) и конфигурация дополнительных активов. Список определяется при каждом запуске; новый актив, встреченный безфильтровым проходом, получает собственную область со следующего запуска.
- Пограничное исчерпание истории (повторный отказ биржи по глубине хранения) завершает перебор одной области, а не всей категории: для многобластной категории option остальные области обходятся; водяной знак фиксируется штатно.
- Предупреждения запуска — пропущенные области, неразрешённые инструменты, непокрытые активы доски — сохраняются с записью запуска и показываются на странице синхронизации при её загрузке, а не только в состоянии компонента сразу после нажатия кнопки.
- `docs/research/bybit-api.md` исправлен по фактам живых запросов: безфильтровое перечисление `instruments-info` покрывает одну доску по умолчанию, `tickers` для option требует `baseCoin`, `execution/list` без фильтра возвращает записи всех активов аккаунта, `delivery-price` непригоден как источник перечня досок.
- Восстановление данных реального журнала — эксплуатационный шаг без кода: сброс состояния категории option, после которого очередной backfill безфильтровым проходом вытянет пропущенную историю ETH/XAUT.

## Capabilities

### New Capabilities

_Нет._

### Modified Capabilities

- `sync/bybit-history`: модифицируется требование `requirement-option-base-coin-coverage` — перечень активов доски строится объединением источников, а не одним перечислением справочника, и дополняется безфильтровым проходом исполнения; модифицируется требование `requirement-history-boundary-guard` — пограничное исчерпание действует в границах одной области перебора; добавляется требование о сохранении предупреждений запуска с записью запуска.

## Impact

- `src/TransactionJournal/Sync/OptionBaseCoinSource.cs` — составной источник: перечисление справочника объединяется с активами сырьевого хранилища (новая зависимость-читатель) и конфигурацией.
- `src/TransactionJournal/Sync/ExecutionCategorySync.cs` — безфильтровая область в перечне областей option; пограничное исчерпание перестаёт прерывать обход остальных областей.
- `src/TransactionJournal/Sync/JournalSyncService.cs`, `JournalSyncResult.cs` — составление предупреждений запуска и их сохранение.
- `src/TransactionJournal/Data/JournalSyncStore.cs` (журнал запусков) — сохранение предупреждений с записью запуска; миграция EF Core для новой колонки.
- `src/TransactionJournal/Components/Pages/Sync.razor`, `SyncJournalReadModel.cs` — показ предупреждений последнего запуска при загрузке страницы.
- Тесты: `tests/TransactionJournal.Tests/Sync` (OptionBaseCoinSource, ExecutionCategorySync, JournalSyncService), `tests/TransactionJournal.Tests/Ui/SyncPageTests`.
- `docs/research/bybit-api.md` — фактическое поведение эндпоинтов перечисления доски.
- Схема БД: новая колонка в `SyncRuns` (миграция); конфигурация и доменные сущности — без изменений.
