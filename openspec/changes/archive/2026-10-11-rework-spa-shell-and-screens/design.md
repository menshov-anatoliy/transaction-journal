# Design

## Context

Каркас SPA собран change'ом `rebuild-frontend-spa` и отретемизирован `reconcile-frontend-with-design`, но механика панелей не реализована: `AppLayout.tsx` даёт лишь сворачивание левой панели иконкой топбара, правые области зашиты в страницы (`grid xl:grid-cols-[minmax(0,1fr)_380px]`), состояние чатов карточки — в URL (`?chats=open`). Решения владельца — grilling-сессия 2026-10-10 (Q1–Q19); визуальный первоисточник правится change'ом `revise-design-screens`.

## Goals / Non-Goals

**Goals:**

- Единая механика панелей в AppLayout: resizable + сворачиваемые, геометрия в localStorage, контекстная правая панель со слотом страниц.
- Экран «Конструкции»: выделение/повторный клик/двойной клик, фильтр области видимости, тулбар с кнопкой прохода подсказок, краткая карточка с индикацией по знаку.
- Карточка: шапка по design.pen (меню «Параметры», Meta-строка, без «В новом окне»), сверки сеток по скриншотам.
- MD-редактор: поле на всю высоту контейнера; вход в SPA по `/` без ошибки.

**Non-Goals:**

- Правки design.pen (change `revise-design-screens`) и агентский чат: SSE-активность, композер, переезд чатов в контекстную панель (change `fix-agent-chat-activity`).
- Серверные изменения: фильтр «Открытые | Все» считается на клиенте по статусам уже загружаемого списка; API не меняется.
- Мобильная раскладка нового каркаса: правые панели остаются шторками по концепции §11, механика не расширяется.

## Decisions

- **D1 — Механика панелей.** В `AppLayout` появляется контейнер из трёх зон: левая панель, центр (`Outlet`), правая контекстная панель. Ширины тянутся сплиттером (drag handle) в границах: левая 4.25–20 rem, правая 20–40 rem; свёрнутая панель схлопывается до иконочной колонки. Свёрнутость и ширины пишутся в localStorage (`tj.layout.left/right`) и восстанавливаются на монтировании; URL-параметры панельной геометрии не используются.
- **D2 — Иконочная колонка.** Каждая панель рендерит вертикальную колонку действий у внутреннего края (вверху); иконка сворачивания — последняя в колонке. Для левой панели иконка сворачивания уходит из топбара; иконки топбара больше не управляют панелями.
- **D3 — Контекстная правая панель.** Страницы регистрируют контекст через Outlet-контекст (хук `useContextPanel()`): `{ content, iconActions }`. Нет регистрации — панель свёрнута (класс `w-0`/скрыта), центр занимает всю ширину; появление контекста разворачивает панель на сохранённую ширину. На списке контекст — краткая карточка выделенной конструкции; на карточке — остаётся текущая панель чатов до change'а `fix-agent-chat-activity`.
- **D4 — Список: выбор и навигация.** Клик по строке — выделение (`?construction=<id>` в URL, переживает перезагрузку/ссылку); клик по другой строке — переключение контекста; повторный клик по выделенной — параметр убирается, панель сворачивается; двойной клик — `window.open('/spa/constructions/<id>')`. Кнопка «Открыть карточку» превью — обычный переход. «В новом окне» из превью удаляется.
- **D5 — Фильтр области видимости.** Сегмент «Открытые | Все» в шапке раздела; состояние `?scope=open|all` (дефолт `open`). Фильтрация клиентская: `open` — конструкции со статусом «открыта»; `all` — все, включая закрытые и архивные. Счётчики шапки и итог сводки всегда считаются по полному набору.
- **D6 — Тулбар и подсказки.** Область «Подсказки журнала» (`JournalHintsArea`) удаляется со страницы списка; в тулбар рядом с «Синхронизировать» добавляется кнопка «Запустить проход подсказок» (`POST /hints/pass`, subject=journal) с индикацией выполнения и результата (обновление бейджей живых подсказок таблицы; ошибка корпуса — агрегированное сообщение). Просмотр подсказок — карточка конструкции и раздел «Подсказки».
- **D7 — Карточка.** Шапка: `Rename`, `Close/Open`, `Archive/Unarchive`, `Delete` (иконочные, по design.pen) + меню «Параметры» с пунктами «Капитал…», «Риск…», «Профит…» (существующие диалоги с эхо-пересчётом); кнопка «В новом окне» удаляется (двойной клик из списка и нативные средства браузера покрывают сценарий). Под заголовком — Meta-строка: `плановый риск <riskUsdt> / плановый профит <profitUsdt> · реальный риск <realRiskUsdt|статус> · капитал <allocatedCapitalUsdt> USDT · открыта <дата>`. Сетки позиций/сделок/закрывающих/корректировок — сверка токенов, отступов и состава с design.pen, приёмка скриншотами.
- **D8 — MD-редактор и вход.** Диалог MD-редактора: высота `h-[80vh]` (в пределах `max-h-[90vh]`), `textarea`/редактор — `height: 100%` контейнера тела диалога, split-view и Ctrl+Enter сохраняются. Vite dev-server: плагин-редирект `/` → `/spa/` (возврат 302 на дев-сервере); `.run`-конфигурации открывают `http://localhost:5173/spa/`.

## Risks / Trade-offs

- localStorage вместо URL для геометрии — решение сессии Q2: ссылка не переносит раскладку, зато панель не «прыгает» между сессиями; URL остаётся за фильтрами и выбором.
- Двойной клик по строке конфликтует с одиночным (первый клик выделит): допустимо — выделение мгновенное, переход по dblclick не мешает.
- Фильтр на клиенте: список конструкций одного владельца мал (десятки строк), серверный параметр не нужен.
