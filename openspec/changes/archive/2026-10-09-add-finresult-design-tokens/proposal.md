# Proposal — design.pen: токены подписи сверхприбыли и минор-заливки убытка

## Why

Сверка frontend с дизайн-системой (`reconcile-frontend-with-design`, ADR 0011) закрыла дрейф токенов, но оставила два осознанных исключения (backlog Q12, [#73](https://github.com/menshov-anatoliy/transaction-journal/issues/73)): подпись сверхприбыли фининдикатора живёт хардкодом `#8a6a1f` (`fin-result-indicator.tsx`), а минор-заливка нереализованного убытка маппится на чужой по смыслу токен riskZone (`#EFB6AE`) — собственного дизайн-токена нет. ADR 0011 объявляет design.pen единственным источником визуальных решений: цвета вне дизайн-системы — дефект сверки, поэтому исключения нужно закрыть в самой дизайн-системе, а не в коде.

## What Changes

- **design.pen**: в дизайн-систему добавляются два семантических токена цвета — подпись сверхприбыли (значение из мастера `#8a6a1f`) и минор-заливка нереализованного убытка (`#EFB6AE` — дизайн-пара из аудита; прежний frontend-цвет `#f6cbc7` был изобретён и не возвращается). Правка выполняется только через MCP pen; машиночитаемый экстракт `.wf-research/design-audit/design-extract.json` перегенерируется.
- **Токен-слой frontend**: новые токены переносятся в `frontend/src/index.css` (hex, конвенция D1 сверки), получают утилиты `@theme inline` и наследуются блоком `--fin-*`; временные комментарии со ссылкой на backlog #73 удаляются.
- **Фининдикатор**: хардкод `text-[#8a6a1f]` заменяется на токен; `--fin-unreal-negative` перенаправляется с riskZone на собственный токен. Все три вида (полный/средний/компактный) повторно принимаются скриншот-сверкой через MCP pen — изменение design.pen после сверки влечёт повторную сверку затронутых экранов (ADR 0011).
- **Spec**: из `ui/design-system` уходит исключение «подпись сверхприбыли» — визуальный слой снова закрывается токенами без оговорок; счётчик переменных 23 → 25 (в предыдущем change счётчик был указан как 24 — фактическое чтение GetVariables показывает 23: 22 цвета + font).

## Capabilities

### New Capabilities

Нет: изменение точечно расширяет существующую дизайн-систему.

### Modified Capabilities

- `ui/design-system`: требование «Визуальный слой строится на дизайн-токенах design.pen» — счётчик переменных растёт до 26, исключение для подписи сверхприбыли фининдикатора удаляется; сценарий вне-токенных цветов закрывает оба бывших исключения.

## Impact

- Код: `design.pen` (через MCP pen), `.wf-research/design-audit/design-extract.json` (переэкстракция), `frontend/src/index.css` (токен-слой), `frontend/src/components/finresult/fin-result-indicator.tsx` (подпись сверхприбыли); tests — только прогон существующих.
- Экраны повторной сверки: карточка конструкции (полный и средний вид), таблица конструкций (компактный вид); evidence — в `.wf-research/design-audit/screenshots/`.
- Зависимости не добавляются; коммиты — Conventional Commits с `refs #73`.
