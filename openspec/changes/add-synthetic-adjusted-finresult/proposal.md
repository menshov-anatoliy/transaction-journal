# Proposal

## Why

При синтетическом закрытии по правилу `ac-43` заголовочные метрики конструкции показывают только инструментальную истину: в кейсе «XAUT направленная PUT 30OCT26 4400» от 15.10.2026 частичное закрытие 0.3 пута (покупка 0.3 XAUTUSDT @ 4141.91 + продажа 0.3 колла @ 5.9) зафиксировало паритетным локом ≈ +35.7 USDT к экспирации, а «Реализованный результат» упал на −46.6 — экономика конструкции не видна первым взглядом, и маркер итога индикатора расходится с насечкой худшего исхода, которая лок уже видит через платёж остатков. ADR-0014/0015 сознательно сохраняют инструментальную истину заголовков, но читатель карточки не получает числового ответа «сколько зафиксировано и каков итог с учётом этого» — только строку лока по каждой связке.

## What Changes

- Сводная величина логического слоя «с учётом зафиксированного синтетикой»: «Реализованный результат» + сумма локов действующих связок; чистая функция над уже вычисляемыми строками, без новых хранилищ.
- Величина не меняет инструментальных метрик: остатки позиций, «Реализованный результат», нереализованный PnL, итог, статус закрытия и индикатор финрезультата остаются нетронутыми (вариант «не пересчитывать индикатор» фиксируется явно).
- Карточка конструкции показывает сводную величину в зоне синтетики метрик (макет `design.pen` сначала, затем перенос).
- Подсказка чтения индикатора объясняет случай «насечка правее маркера»: остатки зафиксированы синтетикой, заголовочный итог их ещё не видит.

## Capabilities

### New Capabilities

(нет — изменение развивает существующие capabilities)

### Modified Capabilities

- `domain/synthetic-close`: логический слой дополняется сводной величиной «с учётом зафиксированного синтетикой» — суммой «Реализованного результата» и локов действующих связок с инвариантами неизменности инструментальных метрик и независимости от марок.
- `ui/screens`: карточка конструкции показывает сводную величину в зоне синтетики; подсказка чтения индикатора упоминает синтетическую фиксацию при расхождении насечки и маркера.

## Impact

- `src/TransactionJournal.Infrastructure`: read-model деталей конструкции (суммирование действующих связок), API-контракт карточки — новое поле.
- `src/TransactionJournal.Application`: строка сводки деталей конструкции.
- `design.pen`: экран «Карточка конструкции» — зона синтетики со сводной величиной (правка раньше frontend).
- `frontend`: `metric-strip.tsx` — отображение сводной величины; текст подсказки чтения индикатора.
- `tests`: read-model (сумма, оспаривания/ручные связки, деградация без марок), API-контракт, отображение.
- Зависимость: текстовые дополнения подсказки опираются на активный change `add-finresult-reading-tooltip` (подсказка чтения индикатора).
- Не меняются: «Реализованный результат» (FIFO), нереализованный PnL, реальный риск, `worstCaseUsdt`, индикатор финрезультата, статус закрытия (ADR-0006, ADR-0014, ADR-0015).
