# Spec Delta

## ADDED Requirements

### Requirement: Панель «Консультации» в деталях конструкции

Экран деталей конструкции SHALL содержать панель «Консультации»: список диалогов консультации этой конструкции, начало нового диалога первым сообщением, удаление диалога целиком. Ответ ассистента SHALL стримиться по мере генерации; между текстовыми сегментами SHALL показываться статусные строки tool-вызовов, сами tool-call фрагменты SHALL не рендериться; генерация SHALL отменяться кнопкой. Чат SHALL быть read-only: UI не предоставляет мутаций журнала и сохранения планов — план управления остаётся markdown-текстом ответа; открытая конструкция ведётся в режиме управления, закрытая — в пост-мортеме ([#45](https://github.com/menshov-anatoliy/transaction-journal/issues/45), [ADR-0009](../../../../../../docs/adr/0009-consultation-chat-architecture.md)).

Traceability ID: requirement-ui-consultation-panel

#### Scenario: Новый диалог начинается первым сообщением
Traceability ID: scenario-ui-dialogue-started-by-message
- **WHEN** владелец отправляет первое сообщение в панели «Консультации»
- **THEN** создаётся новый диалог и появляется в списке диалогов конструкции

#### Scenario: Ответ стримится со статусными строками инструментов
Traceability ID: scenario-ui-streaming-with-tool-status
- **WHEN** ассистент генерирует ответ с рыночными инструментами
- **THEN** текст появляется постепенно
- **AND** между сегментами видны статусные строки tool-вызовов, а их фрагменты не рендерятся

#### Scenario: Генерация отменяется кнопкой
Traceability ID: scenario-ui-cancel-generation
- **WHEN** владелец нажимает отмену во время генерации
- **THEN** стриминг останавливается и панель возвращается в состояние ввода

#### Scenario: Закрытая конструкция — пост-мортем в панели
Traceability ID: scenario-ui-closed-construction-postmortem
- **WHEN** панель «Консультации» открыта у закрытой конструкции
- **THEN** ассистент ведёт разбор финального состояния в режиме работы над ошибками

#### Scenario: Чат не предоставляет мутаций журнала
Traceability ID: scenario-ui-chat-read-only
- **WHEN** владелец работает с панелью «Консультации»
- **THEN** UI чата не предлагает записей в журнал и сохранения планов
