# Proposal

## Why

Движок подсказок отвечает на вопрос «что правилом покрывается сейчас», но владельцу не с кем обсудить конструкцию: почему правило сработало, как читать текущую доску, что делать по факту события. Решения карты [#45](https://github.com/menshov-anatoliy/transaction-journal/issues/45) фиксируют форму: интерактивный read-only чат с ИИ-помощником в контексте одной конструкции, с живым рынком через инструменты и деградацией без рынка; архитектура — [ADR-0009](../../../docs/adr/0009-consultation-chat-architecture.md), доменная модель — [CONTEXT.md](../../../CONTEXT.md) («Консультация», «Диалог консультации», «Сообщение диалога»).

## What Changes

- Новый проект окружения `src/TransactionJournal.Consultations` по образцу Hints (ADR-0007/0008): домен о нём не знает, порты в самом проекте, адаптеры в Infrastructure и composition root.
- Детерминированный снимок контекста в markdown с as-of: конструкция с позициями и результатами, портфельные агрегаты и лимиты, компактный индекс корпуса правил, инструкции агента; живые подсказки движка (синтетика) в контекст не входят; рынок — только через инструменты в момент сообщения.
- Read-only инструменты `read_rule_card(cardId)`, `get_market_snapshot(baseCoin)`, `get_option_board(baseCoin)` через единый `BybitTickersClient` с троттлером; агентный цикл MEAI с потолком `MaximumIterationsPerRequest = 6` (≈6 биржевых запросов на сообщение).
- Деградация при недоступности Bybit: тул возвращает «недоступно + последняя кэшированная проекция с явным as-of», модель обязана помечать устаревшие данные и отказываться от рыночно-зависимых рекомендаций.
- Панель «Консультации» на экране деталей конструкции: диалоги «один вопрос — один диалог», стриминг ответов со статусными строками tool-вызовов, отмена генерации; открытые конструкции — режим управления, закрытые — пост-мортем; чат read-only, план управления — markdown-текст в чате.
- История консультаций в SQLite per construction как запись окружения (порт `IConsultationStore`): рыночный след ответа ассистента сохраняется в сообщении; пересбор стирает консультации.
- Отдельная конфигурация модели чата: keyed `IChatClient`, дефолт z.ai GLM-5.3, смена модели конфигурацией без кода, бюджет <$5/мес.

## Capabilities

### New Capabilities

- `consultations/context`: снимок контекста консультации и инструкции агента — детерминированная сборка с as-of, состав (конструкция, портфельные агрегаты, индекс корпуса), исключение живых подсказок движка, редактируемый `consultation-prompt.md` с обязательными принципами (сценарии если/то, цитирование карточек, маркировка «вне корпуса правил», read-only), пост-мортем закрытых конструкций.
- `consultations/tools`: инструменты и деградация — три read-only тула, один вызов = один HTTP-запрос через `BybitTickersClient`, потолок итераций агентного цикла, кэш as-of при недоступности рынка, конфигурация keyed `IChatClient`.
- `consultations/history`: доменная модель записи и персистентность — Консультация/Диалог/Сообщение, изоляция диалогов, рыночный след, hard-delete диалога, SQLite per construction, стирание пересбором.

### Modified Capabilities

- `architecture/solution-structure`: в фиксированную раскладку DDD-слоёв добавляется шестой проект `TransactionJournal.Consultations` (окружение, зависимость только от Domain) и уточняется направление зависимостей.
- `ui/screens`: на экране деталей конструкции добавляется панель «Консультации» — стриминг, статусные строки tool-вызовов, отмена, управление диалогами, режимы открытых/закрытых конструкций.

## Impact

- `src/TransactionJournal.Consultations` (новый): порты `IConsultationContextReader`, `IRuleCorpusReader`, `IConsultationStore`, агентный цикл MEAI (`UseFunctionInvocation`), инструкции агента, стриминг ответа.
- `TransactionJournal.Infrastructure`: адаптер SQLite-хранилища консультаций по образцу `HintStore`; расширение DTO `BybitTicker` опциональными полями (греки/IV/OI/бид-аск/фандинг) тем же эндпоинтом — существующие потребители не меняются.
- `TransactionJournal` (Web): composition root — keyed `IChatClient` (z.ai GLM-5.3), адаптеры корпуса поверх `RulesCorpusLoader`, панель «Консультации» в деталях конструкции, настройки (модель, путь инструкций).
- Зависимости: `Microsoft.Extensions.AI` в проекте окружения; новых внешних сервисов нет.
- Приёмка: детерминированные контракт-тесты (снимок контекста, инструменты, персистентность, деградация) + живая приёмка владельцем; LLM-вывод фикстурно не тестируется ([#45](https://github.com/menshov-anatoliy/transaction-journal/issues/45)).
- Реализация — после `add-summary-channels` (реуз конфигурации провайдера).
