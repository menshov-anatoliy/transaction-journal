# Proposal

## Why

Итог по журналу сегодня — единственное число в верхней панели и в сводке экрана «Конструкции»: по нему не видно, какая часть результата зафиксирована сделками, а какая живёт оценкой марок и меняется вместе с рынком. Разбивка на реализованный и нереализованный P&L в тех же местах даст понимание структуры результата без открытия деталей каждой конструкции.

## What Changes

- Метрики журнала уровня журнала дополняются агрегатами: реализованный PnL журнала — сумма реализованных PnL всех конструкций, доступен всегда; нереализованный PnL журнала — сумма нереализованных оценок, null при сбое марок хотя бы одной конструкции. Семантика итога не меняется: сумма итогов конструкций, null при неполных данных.
- Верхняя панель рядом с итогом по журналу показывает разбивку на реализованный и нереализованный P&L; при сбое марок нереализованная часть помечается недоступной, реализованная остаётся видимой.
- Сводка журнала на экране «Конструкции» показывает те же величины разбивки рядом с итогом.

## Capabilities

### New Capabilities

_None_

### Modified Capabilities

- `analytics/performance`: новое требование агрегатов уровня журнала — реализованный и нереализованный PnL журнала с правилами доступности при сбое марок.
- `ui/screens`: верхняя панель и сводка экрана «Конструкции» показывают разбивку итога по журналу на реализованный и нереализованный P&L с деградацией только нереализованной части при сбое марок.

## Impact

- `src/TransactionJournal/Analytics/JournalMetrics.cs` — новые поля `RealizedPnL` и `UnrealizedPnL` уровня журнала.
- `src/TransactionJournal/Analytics/JournalMetricsReadModel.cs` — вычисление агрегатов из метрик конструкций.
- `src/TransactionJournal/Components/Pages/ConstructionListReadModel.cs` — `ConstructionListData` несёт разбивку в сводку экрана «Конструкции».
- `src/TransactionJournal/Components/Pages/Constructions.razor` и `src/TransactionJournal/Components/Layout/MainLayout.razor` — вывод разбивки рядом с итогом.
- Тесты: `JournalMetricsReadModelTests`, `ConstructionListReadModelTests`, `AppFrameTests`, `ConstructionListScreenTests`.
- Хранилище, миграции и доменные правила не затрагиваются: агрегаты производны и вычисляются при чтении.
