# Spec Delta

## MODIFIED Requirements

### Requirement: Комментарии редактируются на месте своего уровня
Комментарий сделки SHALL редактироваться в таблице сделок, комментарий позиции — в таблице позиций, комментарий конструкции — в шапке деталей. Редактирование SHALL выполняться многострочным текстовым полем, допускающим переносы строк; сохранённый текст SHALL воспроизводиться без искажений. Сохранение комментария SHALL не требовать перезагрузки экрана и SHALL немедленно показывать обновлённый текст. Отображение SHALL рендерить текст комментария из Markdown: заголовки, списки, выделение и код показываются форматированными, а не исходной разметкой. Одиночный перенос строки SHALL отображаться разрывом строки. Сырой HTML в комментарии SHALL отображаться как текст и SHALL NOT исполняться браузером.

Traceability ID: requirement-comments-inline-editing

#### Scenario: Комментарий сделки редактируется в таблице сделок
Traceability ID: scenario-trade-comment-inline-edit
- **WHEN** пользователь редактирует комментарий сделки в деталях конструкции
- **THEN** новый текст сохраняется и сразу виден в строке сделки

#### Scenario: Комментарий позиции доступен без редактирования остатка
Traceability ID: scenario-position-comment-without-residual-edit
- **WHEN** пользователь редактирует комментарий позиции
- **THEN** доступно только текстовое поле комментария, а остаток позиции не редактируется

#### Scenario: Комментарий вводится многострочно и сохраняет переносы
Traceability ID: scenario-comment-multiline-textarea-edit
- **WHEN** пользователь редактирует комментарий любого уровня и вводит текст в несколько строк
- **THEN** комментарий сохраняется вместе с переносами строк
- **AND** повторное редактирование показывает сохранённый текст без искажений

#### Scenario: Комментарий отображается отрендеренным из Markdown
Traceability ID: scenario-comment-renders-markdown
- **WHEN** комментарий содержит разметку Markdown (список, выделение, фрагмент кода)
- **THEN** отображение показывает форматированный текст, а не исходную разметку

#### Scenario: Одиночный перенос отображается разрывом строки
Traceability ID: scenario-comment-single-newline-breaks-line
- **WHEN** комментарий содержит перенос строки без пустой строки и без разметки Markdown
- **THEN** отображение разрывает строку в месте переноса

#### Scenario: Сырой HTML отображается как текст
Traceability ID: scenario-comment-raw-html-escaped
- **WHEN** комментарий содержит фрагмент сырого HTML
- **THEN** разметка отображается как текст и не исполняется браузером
