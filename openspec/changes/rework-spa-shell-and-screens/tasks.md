# Tasks

Порядок: каркас блокирует экраны. Приёмка экранов — скриншот-сверка с design.pen, обновлённым change'ом `revise-design-screens` (сначала его этап). Тесты — по `.github/prompts/unittests.prompt.md`.

## 1. Каркас и вход

- [ ] 1.1 `AppLayout`: три зоны (левая панель / центр / правая контекстная), сплиттеры ширины (левая 4.25–20 rem, правая 20–40 rem), persistence геометрии в localStorage (`tj.layout.*`), восстановление на монтировании. Проверить: `scenario-frame-panel-geometry-persists`.
- [ ] 1.2 Иконочная колонка панелей: вертикальный ряд действий вверху у внутреннего края; сворачивание — последняя иконка колонки; убрать иконку сворачивания левой панели из топбара. Проверить: `scenario-frame-collapse-icon-in-panel-column`.
- [ ] 1.3 Слот контекстной правой панели (Outlet-контекст `useContextPanel`): без регистрации контекста панель свёрнута, центр на всю ширину; регистрация разворачивает на сохранённую ширину. Проверить: `scenario-frame-context-panel-collapsed-without-context`.
- [ ] 1.4 Vite: redirect `/` → `/spa/` на dev-сервере; `.run`-конфигурации открывают `/spa/`. Проверить: вход по `http://localhost:5173/` открывает SPA без ошибки base URL.

## 2. Экран «Конструкции»

- [ ] 2.1 Выделение: клик — `?construction=<id>` и краткая карточка в контекстной панели; клик по другой строке — переключение; повторный клик по выделенной — снятие выделения и сворачивание панели; двойной клик — карточка в новом окне (`window.open`). Проверить: `scenario-list-row-click-selects`, `scenario-list-second-click-collapses-context-panel`, `scenario-list-double-click-opens-new-window`.
- [ ] 2.2 Фильтр области видимости: сегмент «Открытые | Все» в шапке, `?scope=open|all` (дефолт `open`), клиентская фильтрация по статусу (все — включая архивные); счётчики и итог сводки — по полному набору. Проверить: `scenario-list-scope-open-default`, `scenario-list-scope-all-shows-archived`.
- [ ] 2.3 Тулбар: кнопка «Запустить проход подсказок» рядом с «Синхронизировать» (POST `/hints/pass`), индикация выполнения, обновление бейджей живых подсказок; удалить `JournalHintsArea`. Проверить: `scenario-ui-manual-pass-runs-engine`, `scenario-ui-manual-pass-corpus-error`.
- [ ] 2.4 Краткая карточка в контекстной панели: превью по design.pen; цветовая индикация чисел по знаку (реализов./нереализов./итог — зелёный/красный, риск — красный, плановые границы — приглушённые); действие только «Открыть карточку». Проверить: `scenario-list-context-panel-brief-card`.
- [ ] 2.5 Таблица: сверка внешнего вида с design.pen (шапка над таблицей, 13 колонок, миниатюра индикатора в колонке «Итог», внутрянка) — скриншот-сверка. Проверить: `requirement-screenshot-acceptance`.

## 3. Карточка конструкции
