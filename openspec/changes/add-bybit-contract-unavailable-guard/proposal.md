# Proposal

## Why

Синхронизация прерывается ошибкой биржи `retCode=110023` («The contract is not available for trades»): Bybit отказывает в выдаче истории по контракту, недоступному для торговли. Реальный триггер — проход области базового актива делистнутой опционной доски, которую движок запрашивает намеренно (активы из справочника плюс делистнутые из конфигурации `Sync:ExtraOptionBaseCoins`): биржа вместо пустого списка отвечает отказом. Отказ детерминированный, поэтому каждый повторный запуск падает на той же области: водяной знак не фиксируется, история остальных областей и категорий не догружается.

## What Changes

- Детект отказа «контракт недоступен»: `BybitApiException` получает хелпер распознавания `retCode=110023` (текст сообщения биржи не участвует — код устойчив, текст варьируется).
- Graceful-обработка на уровне движков категорий: отказ `110023` при проходе окна области означает «область недоступна» — обход окон этой области прекращается без ретраев, факт пропуска фиксируется, перебор продолжается со следующими областями и категориями. Для категорий с единственной областью без фильтра (linear-исполнение, delivery-проход) пропуск области означает завершение прохода этой категории.
- Запуск при пропуске завершается успешно со штатной фиксацией водяного знака — по прецеденту защитного контура границы хранения истории (`requirement-history-boundary-guard`).
- Пропущенные области возвращаются в результатах движков и показываются пользователю на странице синхронизации, чтобы пропуск не был безмолвной дырой в данных.

## Capabilities

### New Capabilities

_Нет._

### Modified Capabilities

- `sync/bybit-history`: добавляется требование `requirement-contract-unavailable-area-skip` — отказ биржи «контракт недоступен» (`retCode=110023`) при запросе окна области пропускает область без сбоя запуска, с фиксацией факта пропуска и видимостью пользователю.

## Impact

- `src/TransactionJournal/Bybit`: `BybitApiException` — хелпер `IsContractUnavailableError`; `BybitResilience` без изменений (код 110023 и сегодня не ретраится).
- `src/TransactionJournal/Sync`: `ExecutionCategorySync` и `DeliveryCategorySync` — исход защищённого прохода окна пополняется исходом «область недоступна», циклы областей обрабатывают пропуск; `ExecutionCategorySyncResult` и `DeliveryCategorySyncResult` — перечень пропущенных областей.
- `src/TransactionJournal/Components/Pages/Sync.razor` — показ перечня пропущенных областей рядом с результатом запуска.
- Тесты: `tests/TransactionJournal.Tests/Bybit` (детект кода), `tests/TransactionJournal.Tests/Sync` (пропуск области, продолжение перебора, успешная фиксация водяного знака), `tests/TransactionJournal.Tests/Ui` (видимость пропуска).
- Схема БД и конфигурация: без изменений.
