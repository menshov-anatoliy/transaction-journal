# Tasks

## 1. Механика резервного копирования

- [ ] 1.1 Создать `IJournalBackupService` и `JournalBackupService` (короткоживущий контекст, `VACUUM INTO` с экранированным путём, выбор свободного имени `journal-<время>-<причина>.db` при коллизии секунды) и проверить юнит-тестами: копия создаётся, воспроизводит данные с учётом незачекпоинченного WAL, имя различает причины (`requirement-backup-consistent-snapshot`)
- [ ] 1.2 Реализовать ротацию «лучшие усилия» (удаление старейших за лимитом по `LastWriteTimeUtc`, ошибки — предупреждения, свежайшая копия не удаляется) и проверить юнит-тестами сценарии `requirement-backup-retention`, включая неудачу удаления без отмены операции
- [ ] 1.3 Добавить чтение конфигурации `Backup:Directory` (по умолчанию `App_Data/backups`) и `Backup:RetentionLimit` (по умолчанию 15) в стиле `SyncOptionsReader` и проверить тестом значения по умолчанию и переопределения из конфигурации
- [ ] 1.4 Зарегистрировать сервис в DI `Program.cs` (singleton над собственными опциями контекста) и убедиться, что приложение стартует без ошибок
