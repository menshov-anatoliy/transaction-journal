# Spec Delta

## ADDED Requirements

### Requirement: Паттерн Tooltip в design.pen

Дизайн-система design.pen SHALL изображать паттерн Tooltip — всплывающую подсказку метрики: свёрнутое состояние как значение или заголовок колонки с пунктирным подчёркиванием без иконок-триггеров и открытое состояние как попап на дизайн-токенах с заголовком метрики и разделами по каждому показателю. Макет SHALL изображать оба состояния; подсказка не должна изображаться нативной системной всплывающей подписью.

Traceability ID: requirement-design-metric-tooltip-pattern

#### Scenario: Макет изображает оба состояния подсказки
Traceability ID: scenario-design-tooltip-both-states
- **WHEN** паттерн Tooltip открывается в design.pen
- **THEN** в макете присутствуют свёрнутое состояние (значение с пунктирным подчёркиванием) и открытое состояние (попап с разделами по показателям)

#### Scenario: Подсказка собирается из существующих токенов
Traceability ID: scenario-design-tooltip-token-alignment
- **WHEN** паттерн Tooltip переносится во frontend
- **THEN** попап собирается из существующих токенов и паттернов дизайн-системы без введения цветов и шрифтов вне системы
