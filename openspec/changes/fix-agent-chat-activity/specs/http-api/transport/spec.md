# Spec Delta

## MODIFIED Requirements

### Requirement: Ответы ИИ-помощника стримятся по SSE

Генерация ответа ИИ-помощника SHALL передаваться в SPA серверными событиями (SSE): токены SHALL приходить потоком; начало/завершение/ошибка SHALL быть событиями протокола; polling по HTTP-каналу чата SHALL отсутствовать. Стрим SHALL дополнительно доставлять события активности инструментов: перед вызовом инструмента реестра — событие с именем инструмента и фазой начала, после завершения вызова — с фазой конца; события активности SHALL не нарушать инвариант ровно одного терминального события (`done` или `error`). Payload события ошибки SHALL содержать человекочитаемую причину отказа (ненастроенный ключ провайдера, недоступность провайдера, ошибка модели), достаточную для показа владельцу без расшифровки кодов.

Traceability ID: requirement-http-api-sse-chat-streaming

#### Scenario: Токены ответа приходят потоком
Traceability ID: scenario-chat-tokens-stream-over-sse
- **WHEN** владелец отправляет сообщение в чате агента
- **THEN** SPA получает ответ ИИ-помощника потоковыми событиями SSE по открытому соединению

#### Scenario: Активность инструментов приходит событиями стрима
Traceability ID: scenario-chat-tool-activity-streamed
- **WHEN** генерация ответа вызывает инструменты реестра
- **THEN** стрим доставляет события с именем инструмента и фазой начала/конца до появления токенов результата
- **AND** терминальное событие остаётся единственным (`done` или `error`)

#### Scenario: Ошибка генерации доставляется событием SSE
Traceability ID: scenario-chat-error-delivered-as-sse-event
- **WHEN** генерация ответа завершается ошибкой провайдера
- **THEN** SPA получает событие ошибки по тому же SSE-соединению и показывает деградацию без потери истории чата

#### Scenario: Причина отказа видна в UI
Traceability ID: scenario-chat-error-cause-visible-in-ui
- **WHEN** генерация невозможна (ненастроенный ключ, недоступный провайдер, ошибка модели)
- **THEN** событие ошибки несёт человекочитаемую причину и UI показывает её владельцу
