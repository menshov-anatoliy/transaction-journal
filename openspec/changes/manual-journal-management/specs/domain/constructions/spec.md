# Spec Delta

## MODIFIED Requirements

### Requirement: Закрытие позиции обнуляет чистый остаток
Закрытие позиции SHALL выполняться обнулением чистого остатка: встречными сделками, закрывающими записями delivery/OTM-экспирации (по ADR-0002, из синхронизации) или ручной пометкой закрытия. Ручная пометка SHALL быть fallback-средством для инструментов без биржевых записей закрытия и штатным способом закрытия при ручном ведении журнала; цена пометки SHALL задаваться пользователем со значением по умолчанию — последней известной маркой. Пометка SHALL иметь опциональное количество: незаданное количество SHALL закрывать весь остаток на момент пометки, заданное — указанную часть остатка. Ручная пометка SHALL свободно правиться и удаляться, возвращая позицию в открытое состояние.

Traceability ID: requirement-position-close-lifecycle

#### Scenario: Остаток обнуляется встречными сделками
Traceability ID: scenario-close-by-offsetting-trades
- **WHEN** чистый остаток позиции становится нулевым после очередной сделки
- **THEN** позиция считается закрытой сделками, без специальных записей

#### Scenario: Ручная пометка закрывает позицию инструмента без биржевых записей
Traceability ID: scenario-manual-mark-delistings
- **WHEN** инструмент позиции делистингован, биржевых записей закрытия нет, и пользователь ставит ручную пометку с ценой
- **THEN** позиция закрывается по цене пометки и участвует в результате наравне со сделками

#### Scenario: Ручная пометка по умолчанию берёт последнюю марку
Traceability ID: scenario-manual-mark-default-last-mark
- **WHEN** пользователь ставит ручную пометку и не задаёт цену
- **THEN** система подставляет последнюю известную марку инструмента

#### Scenario: Частичная пометка закрывает часть остатка
Traceability ID: scenario-manual-mark-partial-quantity
- **WHEN** пользователь ставит пометку с количеством меньше остатка позиции
- **THEN** закрывается указанная часть, а позиция остаётся открытой на разницу

#### Scenario: Удаление пометки возвращает позицию в открытую
Traceability ID: scenario-mark-removal-reopens
- **WHEN** пользователь удаляет ручную пометку закрытия
- **THEN** позиция снова считается открытой с прежним остатком
