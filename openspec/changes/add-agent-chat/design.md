# Design

## Context

Решения приняты grilling-раундами в [#53](https://github.com/menshov-anatoliy/transaction-journal/issues/53) по требованиям карты [#50](https://github.com/menshov-anatoliy/transaction-journal/issues/50); архитектурная рамка — [ADR-0009](../../../docs/adr/0009-consultation-chat-architecture.md) (проект окружения, порты внутрь, ME.AI, read-only инструменты) остаётся действующей.

## Decisions

1. **Замена, не сосуществование**: одна сущность «Чат агента» вытесняет «Консультацию» и «Диалог консультации». Blazor-UI удаляется после паритета, две записи окружения одной природы в новом UI не выживут.
2. **Плоский чат**: единая полная история без вложенных «один вопрос — один диалог»; изоляция тем достигается новым чатом (список сессий дизайн-референса).
3. **Привязка опциональна и неизменяема**: фиксируется при создании; смена контекста = новый чат. Просмотр чатов из карточки конструкции — фильтр по привязке.
4. **«Завершён» — ручная метка**: без автоматики по бездействию; продолжение возвращает в активные; удаление — отдельное действие, целиком, без корзины.
5. **Источники данных — закрытый справочник из трёх**: журнал, корпус правил, рынок Bybit; набор — параметр чата (дефолт — все), всё read-only.
6. **Модель — параметр чата**: дефолт GLM-5.3, сменяема на лету; история не переписывается. Расширяет ADR-0009 («смена модели без кода») на уровень чата.
7. **След источников**: обобщение рыночного следа — инструменты + ссылки на карточки правил и данные журнала с as-of; UI рендерит из него ссылки.
8. **Хранение и пересбор**: единое SQLite-хранилище чатов как запись окружения; пересбор стирает привязанные чаты вместе с конструкциями, непривязанные переживают.
9. **Без миграции истории**: старые per-construction базы консультаций не конвертируются — история мала, привязана к удаляемому UI, пересбор и так стирает её безвозвратно.
10. **Контекст без конструкции**: портфельный снимок журнала (агрегаты, лимиты, индекс корпуса) с as-of — тот же принцип «первичные факты в промпте», без раздела конструкции. Пост-мортем закрытой конструкции переносится без изменений.

## Non-goals

- API-контракт нового SPA и UI чата — после реализации [#19](https://github.com/menshov-anatoliy/transaction-journal/issues/19) и остальных тикетов карты [#50](https://github.com/menshov-anatoliy/transaction-journal/issues/50).
- Мультиагентность (несколько ИИ-помощников с разными ролями) не вводится.
