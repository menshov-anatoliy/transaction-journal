# Proposal

## Why

По правилам торговли владельца фьючерсные контракты конструкции всегда должны быть закрыты по рискам опционами этой же конструкции; опционы могут оставаться незакрытыми. Сейчас незакрытый риск виден только агрегатным статусом `unbounded` реального риска — без указания, какая именно нога не закрыта и какая часть позиции. В grilling-сессии 2026-10-18 утверждена одноуровневая модель: все незакрытые риски — предупреждения (категория «ошибка» отклонена владельцем), канонический термин неограниченного вкуса — «Риск не ограничен».

## What Changes

- Новый вычислитель диагностики в Application-слое: алгебра наклонов платежа на хвостах оси цены, группировка по базовому активу через все экспирации (паритет USDT/USDC), приоритет покрытия фьючерсной части встречными длинными опционами; частичное покрытие выражается числом незакрытых контрактов.
- Диагностика вычисляется на лету при чтении из текущих открытых остатков и не хранится; конструкция без открытых остатков — без предупреждений.
- Запись предупреждения: инструмент, число незакрытых контрактов, причина («убыток не ограничен» / «убыток ограничен ценой входа» / «убыток ограничен нулём цены»), текст на русском.
- Отображение: бейдж-счётчик «⚠ N» в строке списка конструкций (по образцу бейджа живых подсказок), полный перечень в краткой карточке контекстной панели и в секции «Предупреждения» основной карточки над таблицами записей; бейдж «∞» индикатора финрезультата сохраняется.
- Контракты API пополняются аддитивно: счётчик предупреждений в строках списка/превью, коллекция записей в карточке.

## Capabilities

### New Capabilities

- `analytics/risk-diagnostics`: правила вычисления и атрибуции незакрытых рисков из открытых остатков, покрытие по базовому активу через все экспирации, тексты записей, поведение на неразборчивых символах.

### Modified Capabilities

- `ui/screens`: добавлено требование отображения предупреждений конструкции в трёх точках — список, краткая карточка, основная карточка.

## Impact

- `TransactionJournal.Application/Analytics`: новый калькулятор рядом с `RealRiskCalculator` (переиспользует парсеры символов, но не его правило группировки по ранней экспирации); `ConstructionMetrics`, `ConstructionListRows`, `ConstructionDetailRows` — аддитивные поля.
- `TransactionJournal.Infrastructure/ReadModels` и `Api/Constructions`: прокидывание счётчика и записей в список, превью и карточку.
- `design.pen`: сначала макет — бейдж строки, перечень краткой карточки и секция карточки вносятся через MCP Pen по существующим паттернам, включая скрытые состояния.
- `frontend`: перенос из обновлённого макета — бейдж строки таблицы, секция краткой карточки, секция основной карточки.
- Глоссарий: термины «Предупреждения конструкции», «Покрытие фьючерса опционами», переиспользование «Риск не ограничен» в текстах по ногам.
- Вне объёма: Telegram-сводки (change `add-summary-channels`), история и хранение предупреждений, изменение группировки реального риска.
