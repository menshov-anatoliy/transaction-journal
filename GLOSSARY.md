# Журнал сделок (transaction-journal)

Единый словарь проекта журнала сделок: домен сделки, UI-дизайн и инфраструктура.

## Language

### UI-дизайн и сверка

**Дизайн-токен**:
Именованное значение визуального слоя design.pen (переменная `$variables`: цвет, шрифт). Источник истины для цветов и типографики SPA.
_Avoid_: «константа стиля», «переменная темы»

**UI-шов**:
Слой дизайн-токенов и общих переиспользуемых компонентов, через который страницы получают оформление; правится раньше страниц.
_Avoid_: «тема», «скин»

**Токенно-компонентное соответствие**:
Критерий приёмки переноса дизайна: токены, типографика, отступы, радиусы и состав/структура компонентов совпадают с design.pen; попиксельное совпадение не требуется.
_Avoid_: «пиксель-перфект»

**Скриншот-сверка**:
Визуальная приёмка экрана сравнением живой страницы (localhost) с макетом design.pen через MCP pen; обязательный критерий закрытия постраничного таска.

**Экран**:
Топ-уровневый фрейм design.pen (например, пара «Топбар + Body»), сопоставленный маршруту/странице SPA.
_Avoid_: «макет» как синоним экрана

### Индикатор финрезультата

**Плановый риск**:
Расчётный риск конструкции к экспирации по плановым ценам: сумма денег, которую конструкция может потерять, если все сделки дойдут до expiration (riskUsdt). Задаёт левую границу шкалы и красную зону индикатора.
_Avoid_: «текущий риск», «реальный риск»

**Реальный риск**:
Худший сценарий по фактическим ценам и открытым остаткам: сколько денег вернёт ликвидация конструкции сейчас, к ближайшему expiry; 0 после закрытия остатков. Метрика бэкенда, при отсутствии — заглушка плановым риском.
_Avoid_: «плановый риск», «риск позиции»

**Граница реального риска**:
Граница зон индикатора = реализованный результат − реальный риск (реальныйРискEff с каскадом заглушек: метрика → плановый риск → плановый профит → 0). Насечка с подписью «риск есть / X USDT · Y%» или «риска нет».
_Avoid_: «стоп-лосс», «лимит убытка»

**Маркер итога**:
Метка.finresult на полосе индикатора: точка текущего итога (реализованный + нереализованный результат); при сбое котировок подписывается только реализованной частью, а индикатор помечается неполным.
_Avoid_: «точка P&L», «метка цены»

**Сверхприбыль**:
Часть итога выше границы реального риска, когда конструкция уже вышла из зоны риска в плюс; рисуется золотой зоной от границы до маркера.
_Avoid_: «профит», «золотая зона» как синоним сверхприбыли
